## 八 已知环境坑（接手必读）

1. **行尾假改动**：`core.autocrlf=true`；脚本以 `newline='\n'` 写出的文件与 checkout 的 CRLF 混存，曾出现「整文件假 diff」（例：`Q版素材映射.tsv`）。辨别法：`git show HEAD:<file> | tr -d '\r'` 与工作区比对，确认仅 CRLF 差异后 `git checkout --` 还原。
2. **NUL 坏字节**：Bash **裸 heredoc 曾吞反斜杠**（历史坑 #23），导致 md 内出现 NUL（最近一次＝交接索引 byte@15422，已修）。写含反斜杠的文本**用 Write 工具或带引号的 heredoc（`<<'EOF'`）**，勿用裸 heredoc。
3. **「日志无 error ≠ 功能正确」**：krkr 端必须实机/逐屏导出 PNG 目视验收（TJS2 曾出现 opacity 越界静默分叉）；静态检查、审计 0 violation 都不能当「引擎通过」。
4. **图片必须真 alpha（PNG-32）**；超分/补边对照必须从**初始原图**出发，严禁拿 AI 输出当下一轮输入。
5. **curl 不读系统代理**：访问日站须显式 `-x http://127.0.0.1:7897`；FANZA/DMM 对非日本 IP 封锁。
6. **git 纪律**：commit 前 `git branch --show-current`；逐路径 `add`（禁 `-A`）；`merge` 后 HEAD 在 main，不得继续提交；**严禁 `git clean -xfd`**（会连带删除 `.gitignore` 忽略的成品/备份/工具等目录，见 §五）。
7. **磁盘纪律**：不复制大素材、不做多份全量构建；大归档先查余量（当前约 21–22 GiB）按 3× 预估。
