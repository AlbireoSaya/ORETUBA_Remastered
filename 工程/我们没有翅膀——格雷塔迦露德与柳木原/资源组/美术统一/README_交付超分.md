## 四、超分注意（重要）

1. **立绘：已按「内容 bbox 面积最大」选源**，**透明加边已被排除**——选中的是**紧裁版**或 **np 高清版**，不是四周留透明边的那版。
   - **np（涅布）立绘内容面积为本篇的 1.4–2.5 倍**，已优先采用（np 立绘 259 件）。
2. **不要对整张画布做超分**。请按**内容 bbox** 裁切后再处理，处理完**贴回原画布**：
   - **`清单_立绘.tsv` 带 `内容bbox(w,h)` 与 `bbox偏移(x0,y0)` 两列**；
     **`交付清单.tsv` 仅带 `内容bbox(w,h)`，没有 `bbox偏移(x0,y0)`**。
     需要偏移量（裁切起点 `x0,y0`）时请**读分表 `清单_立绘.tsv`**；
   - 立绘多为 RGBA，直接整画布超分会把**透明区一起放大**，产生边缘伪影、并浪费算力。
   - 参考量级：np 立绘 `asu_a01x` 内容 808×720=581,760 vs 本篇 `ot_asu01` 413×558=230,454。
   - **⚠️ `模式 == RGBA` ≠ 有透明底（2026-09-19 实测，W13）**：4,415 件中 **RGBA 共 2,394 件**，
     其中 **1,962 件 `内容bbox == 画布`**（无透明边）；进一步实测**有 246 件 RGBA 图连一个 `alpha == 0` 像素都没有**
     （`CG背景` 148 ＋ `系统UI` 98，例：`cin001.png` 704×269 `A∈[255,255]`、`cin002.png`、`cin003.png`…）。
     → **不得用 `模式` 推断是否需要 bbox 裁切；判据一律是 `内容bbox` 与 `尺寸` 是否相等**
     （`内容bbox == 尺寸` → 免裁切、整图超分；`内容bbox < 尺寸` → 按 bbox 裁切）。
3. **CG背景 / 系统UI 多为不透明图，内容 ≡ 画布**（`内容bbox = 画布`），可直接整图超分；
   但 **系统UI 中相当一部分是 RGBA 透明底**（如 `tl_*`、`gl_*` 文字按钮），这些请同样按 `内容bbox` 裁切处理。
   - 判据同 §四.2：**读 `内容bbox`，不要看 `模式`**（RGBA 里也有 246 件完全不含透明像素）。
   - 注意：**偏移列只在 `清单_立绘.tsv` 有**；`清单_CG背景.tsv` / `清单_系统UI.tsv` / `交付清单.tsv` 都只记录
     `内容bbox(w,h)` 的**宽高**，不记录偏移——需要偏移请对原图用 alpha 包围盒自行求一次。
4. **`未识别` / `未判定` 类已于 2026-09-19 全部判读完毕（W12，403 件全覆盖），两栏现均为 0 件**——
   以下原约束**已解除**：迁移前立绘 182 件「未识别」、CG背景 221 件「未判定」不得当立绘/背景使用；判读后
   167 件已改归 `CG背景\`（判读类别取终裁值），`cit` 15 件判为真立绘留在 `立绘\`，**无遗留「未识别/未判定」**。
   - 编程组 / UI 组若要**程序化过滤**，仍请用 `交付清单.tsv` 的 **`判读类别`** 列（不要用 `类别`）：
     `判读类别 == 立绘` → 真立绘 **1,425**（迁移前 1,410）；`判读类别 == 未识别` → **0**（原 182）；
     `判读类别 == 背景` → 真背景 **322**（迁移后、补回 7 件前为 320；W11g 交付时点迁移前为 295）；`判读类别 == 未判定` → **0**（原 221）。
     系统UI 侧同理按 `判读类别`（存档/图标/标题/消息窗/菜单/转场遮罩/其他）细分。
5. **保留原始字节**：本目录是超分管线的**输入**，请不要在本目录内原地覆盖，输出请另置目录。

### 6.1 超分结果的 18 件 1px bbox 边缘偏移（**如实登记，判定不返工**）

**现象**：超分产物中 **18 / 4,415 件**（补回 7 件前为 18 / 4,408；补回的 7 件均无偏移）的「输出内容 bbox」与「输入内容 bbox × 2」相差 **1 px**（**画布本身严格 2×，无一件偏差**）。

| 类别 | 件数 | 统一名 |
| --- | ---: | --- |
| CG背景 | 2 | `sr2_t06`、`sr2_t07` |
| 系统UI | 16 | `op_03`、`op_15`、`op_22`、`op_23`、`op_27`、`op_28`、`op_32`、`op_33`、`op_36`、`op_37`、`op_3a`、`op_56`、`op_57`、`ss_name1`、`ss_name2`、`tl_chk` |

- **成因**：这 18 件的**内容 bbox 恰好等于整张画布**（内容贴边、无透明边距——实测 18/18 均满足 `内容bbox == 画布`）。
  超分器对**贴边 alpha** 做边缘软化后，重算 alpha 包围盒时最外圈像素的阈值判定落在 ±1 px。
- **容差依据**：`超分任务清单.md` §五.3 明确允许 **±1 px 舍入**（原文：「允许 ±1 px 舍入，需逐条列异常」）。
  本表即该条要求的**逐条异常清单**。
- **结论：不返工**。偏差为边缘 alpha 阈值噪声、画布与宽高比均严格正确，不影响贴回排版（偏移按 ×2 取整即可）。
- **复现**：`超分清单.tsv` 逐行比较 `输出画布 == 输入画布 × 倍数`（0 例外）与 `输出内容bbox == 输入内容bbox × 倍数`（18 例外）。
- 另有 **4,397** 件（补回 7 件前为 4,390 件）输出内容 bbox 与输入 × 倍数**完全相等**。
