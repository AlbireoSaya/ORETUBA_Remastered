**根因（沿用 W7-2 已定位、本模块复核确认）**：R 版**标题槽（`kind=title`）的译文被同文件内另一条正文/旁白台词的译文整条覆盖**（偏移映射错配）。实证：`s01_03d.tob@470` 是 title 槽（JP `彼女からの電話とうろたえる僕`），CN 却是 `#鹰志$&「是时候该学习了——」$`——正是同文件 `@1884` dialogue（JP `さて、そろそろ勉強──`）的译文。**正确标题译文在 R 版语料中不存在 → 只能按 JP 标题重译。**

本模块收录的三组即此根因在「无 `$&` 标记」形态下的表现（W7-2 的 B3＝含 `$&` 的 22 条）。

## 二、修正表格式（与 `修正表_B1B3.tsv` 完全一致）

`修正表_B1B3_扩展.tsv`，UTF-8，制表符分隔，含表头，列为：

```
source  file  locator  kind  field  old_text  new_text  fix_type  method  evidence  confidence
```

| 列 | 取值与含义 |
| --- | --- |
| `source` | 本表全部为 `otr`（R 版） |
| `file` | R 版脚本名（`*.tob`） |
| `locator` | `offset=<n>`（R 版 `工程\我们没有翅膀R\语料\R版迁移映射.json` 以 `(file, offset)` 为槽主键；offset＝该槽正文在 tob 内的字节偏移） |
| `kind` | 全部 `title` |
| `field` | `cn` |
| `old_text` | 现状文本（**逐字符取自源语料 `R版迁移映射.json` 的 `cn`，未规范化**） |
| `new_text` | 修正后文本 |
| `fix_type` | `retranslate`（A/B 组，须人工重译） / `space_strip`（B′ 组，程序化删前导 U+3000） |
| `method` | `manual_retranslate` / `programmatic` |
| `evidence` | 判据与证据（含 JP 标题、证据文件名、定译依据） |
| `confidence` | `high` / `medium` / `low` |

> **`fix_type` 新增值说明**：`space_strip` 为本次新增（W7-2 的枚举为 `quote_add` / `quote_normalize` / `marker_strip` / `retranslate`）。
> 语义＝**程序化删除文本开头的多余全角空格 U+3000**，`new_text = old_text.lstrip('　')`，逐字符可逆。
> **W6 消费方须显式处理该类型**（不可当作 `marker_strip` 的 `#…$&` 剥离）。此点提请主代理确认。
