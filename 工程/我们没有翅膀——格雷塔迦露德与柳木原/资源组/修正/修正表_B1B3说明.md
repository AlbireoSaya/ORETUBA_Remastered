## 一、修正表格式

`修正表_B1B3.tsv`，UTF-8，制表符分隔，含表头，列为：

```
source  file  locator  kind  field  old_text  new_text  fix_type  method  evidence  confidence
```

| 列 | 取值与含义 |
| --- | --- |
| `source` | `otp`＝前奏诗 / `ota`＝After Story / `otr`＝R 版 |
| `file` | 脚本名（otp 为 `*.sob.jsonl`，ota/otr 为 `*.tob`） |

| `new_text` | 修正后文本 |
| `fix_type` | `quote_add` / `quote_normalize` / `marker_strip` / `retranslate` |

## 二、三类修正：判据、方法与计数

### 第 1 类 · B1 外层引号遗漏 —— `fix_type=quote_add`（13 条）

**判据**：`原文含「或」 且 译文不含 “ 或 ”`。

- 前奏诗 59 个 jsonl / **9,059 槽**全扫 → **14 条**命中。
- 其中 **6 条**译文完全无引号（真遗漏）；另 **8 条**译文用了 `‘’`（单引号），归第 2 类。
- After Story `译文.json` / **18,213 槽**全扫 → **7 条**，全部无引号。

**修正规则**：给译文加中文引号 `“…”`，**不得改动其余文字**。
**关键**：前奏诗这 6 条的原文以控制码开头（`<-4>\`、`<8>\`、`<12>\`），**控制码前缀原样留在原位，引号只包住引语部分**。

**根因（前奏诗，可复现）**：`工程\我们没有翅膀 前奏诗\工具\fix_quotes.py:34` 判据是 `jp.startswith('「')`——只处理**以 `「` 开头**的原文；这 6 槽原文以控制码开头被整批跳过。`工具\verify_cn.py:24-26` 只把 `「」` 列为译文**禁用字符**，从不校验「原文有 `「」` ⇒ 译文必须有 `“”`」→ 校验器结构性盲区（审计 §5.2、§九 B11）。

### 第 2 类 · B1附 单引号风格偏差 —— `fix_type=quote_normalize`（8 条）

**判据**：`原文含「 且 译文含 ‘ 或 ’ 且 译文不含 “ 或 ”`。

**先核对通用规范**（`.zcode\skills\galgame-translation\SKILL.md` §七.3）：
> **引号一律转换**：`「」` → `“”`，`『』` → `‘’`（默认转中文引号）。

**结论：通则支持把 `‘’` 改成 `“”`，但前提是原文用的是 `「」` 而非 `『』`。** 已逐条核实本 8 条的 JP **只含 `「」`、不含 `『』`** → 现行 `‘’` 属**误用**（`‘’` 只保留给原文 `『』`／引号内嵌套），应改 `“”`。
（顺带核实：前奏诗全库译文含 `‘’` 的槽共 **174** 条，其中 **100** 条对应 JP 的 `『』`，属正确用法，**不动**；其余 66 条为 `“”` 外层 + `‘’’` 内层的正确嵌套。）

**修正规则**：`‘X’` → `“X”`，其余字符不动（逆变换 `“→‘`、`”→’` 可逐字符还原）。

### 第 3 类 · B3 标题槽脚本标记泄漏 / 内容错位 —— `fix_type=retranslate`（22 条）

**判据**：扫 R 版四份映射（`R版迁移映射.json` / `新增译文映射.json` / `重编码映射.json` / `等长补齐_截断清单.json`）的 `(file,offset)` 并集，取**正文文本字段（`cn`/`text`/`kept`）含 `$&`** 的槽。

**独立复核结果：恰好 22 个唯一 `(file,offset)`**，且**全部 `kind=title`**；**非标题槽含 `$&` 者＝0** → 证实「标记泄漏是标题槽专属现象，正文未被污染」。

**修正规则与结论（重要）**：

诊断给出的规则是「剥掉 `#…$&` 与结尾 `$`，只保留真正的标题文本；若剥完是正文台词则须按日文重译标题」。
**逐条剥离后，22 条的剩余内容 100% 是正文台词（全部以 `「` 开头），没有一条是标题文本** → 因此 **22 条全部归 `retranslate`（人工重译），`marker_strip` 用量为 0**。

**明确结论**

1. **可程序化（21 条）**：B1 的 13 条 + B1附 的 8 条。修正是**纯字符级**操作，逐字符可逆，零副作用，可由 W6 直接按 `old_text → new_text` 字符串替换执行。
