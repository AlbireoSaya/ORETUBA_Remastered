### 一·补、「采用」列判定规则（裁决 B）

对**每个场景**取其全部源行，按归一化指纹分组；优先级 **③ > ① > ②**：

1. **③ 场景全部文本一致（只有一个指纹）** ⇒ 该场景**所有行 `采用=是`**（内容相同，不存在取舍）。
2. **① 场景存在多个不同文本，且有 `ot` 源行** ⇒ **只标 `ot` 行那一行为 `采用=是`**（**即使另一源行与之逐字相同，也只标首选载体**）；同场景其余行 `采用=否`：文字确属变体者备注「变体留档，非采用版（采用版：`<源>/<脚本>`）」，文字与采用版逐字相同者备注「与采用版文本一致（重复行），非首选载体（采用版：…）」。
3. **② 场景存在多个不同文本，但无 `ot` 源行** ⇒ 按 **`otr` > `otv`** 取一版的那一行为 `采用=是`，其余 `采用=否`＋同上备注。
4. **④ 未匹配行**（`otv S01_01` 空占位）⇒ `采用=否`，不参与采用判定。

**计数**：`采用=是` **1200 行** ｜ `采用=否` **53 行**（其中「变体留档，非采用版」41 行、「与采用版文本一致，非首选载体」11 行）；带 `备注` 的行 64。有效场景（不含未匹配伪场景）**449 个**，其中「多文本需取舍」**27 个**（每场景恰 1 行 `是`）、「文本一致全采用」**422 个**。

> 校验口径（验收器的「采用列唯一性」与「缺口不含 C/D」两项断言）：**多文本场景恰有 1 行 `采用=是`**；**文本一致的场景全部 `采用=是`**；`采用=是` 的行必须同属**同一个指纹**，且该指纹必须等于「`ot` > `otr` > `otv`」优先级所选的那一版；未匹配行 `采用=否`；缺口表不含 `ot_s00_00`、不含未匹配伪场景、不含空指纹行。

## 一、归一化与去重指纹（完整规则）

`简介jp` 的**字符串直比不能用来判重**：同一段文本在 `ot`（真换行）/`otr`（TSV 内以字面 `\n` 表示换行）/`otv`（源脚本本就写字面 `\n`）里换行写法不同。故先做**归一化指纹**再判重：

```
def fingerprint(text):
    t = text.replace('\\n', '')          # ① 去行内换行（字面两字节 反斜杠+n）
    t = ''.join(ch for ch in t if not ch.isspace())   # ② 去全部空白，含 U+3000 全角空格
    t = t.replace('\u301c', '\uff5e')     # ③ 统一 〜(U+301C) → ～(U+FF5E)
    return t
```
- **只做这三步**：不转半角/全角、不合并 `≪≫` 与 `<<>>`、不动标点、不动专名写法（后两者属 R/PSV 版与 2009 版的真实差异，必须保留为不同指纹）。
- **同指纹 = 同一段文本 ⇒ 同一 `重复组id`**；**只标记、不删行**（用户要求「找出重复的片段并进行标记」）。
- `重复组id` 形如 `R001`，按**交付主表行序首次出现**赋号（确定性、幂等）。
