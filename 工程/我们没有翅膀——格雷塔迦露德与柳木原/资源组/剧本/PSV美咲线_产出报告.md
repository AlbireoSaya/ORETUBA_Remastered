## 二、schema 遵循与「枚举取值扩展」说明（**字段结构未改**）

`scene.jsonl` 的字段表（`schema.md` §一/§二）**逐字段照用**，未增删任何字段、未改任何嵌套结构。
但 schema 的若干**枚举取值是 W6a 按亚衣线（`otr`）语境定的**，本模块为新源，必须做**取值扩展**；
以下逐项说明，均为「新源必须有的一个值」，非新字段：

| 字段 | W6a 取值 | otv 取值 | 理由 |
| --- | --- | --- | --- |
| `source` | `otr` | **`otv`** | 结构来源代号＝PSV 美咲线；与总纲 §七 I1 的六源代号一致（`ot`/`otr`/`ota`/`otp`/`otv`/`np`） |
| `text_source` / `cn_base` / `cn_origin` | `ot` / `otr_new` / `mixed` / `fix_table` / `retranslate` / `empty` | **`otv`**（+ `empty`） | 取文基准层就是 otv 语料本身。`修正\_README.md` §四.5 的门控映射表已按此约定预置 `otp→otp`、`ota→ota`；otv 同构，构建器已登记 `otv→otv` |
| `lines[].kind` | `title` / `dialogue` / `narration` | `dialogue` / `narration` / **`summary`** | PSV 源字段「类别」只有 `台词` / `梗概` 两值；`梗概`（`SceneJumpDialog` / `MessageSwitch_Tag` 的 `:Text`）**是场景跳过的梗概文、不是台词**（PSV 作品 skill §三、资源说明 §5 明示），与「旁白」语义不同，故**如实标为 `summary`**，不塞进 `narration`（塞进去会污染 `cast` 与「旁白」统计，属信息丢失）。本模块无 `title` 槽（标题不在消息表里，见 §2.1） |
| `align_method` | `audit` / `jp_exact_fallback` / `new_scene_direct` / `empty_slot` / … | **`new_scene_direct`** / `empty_slot` | 复用既有取值：otv 全部场景无 2009 对照，取文即「直接取该源语料」，与 `new_scene_direct` 的定义完全吻合；空槽用 `empty_slot` |
| `stats.lines_by_source` | `{mig, new, None}` | **`{otv, empty}`** | 该字段记录「源 `src` 流」（R 版侧 mig/new 之分）。otv 语料是**本项目独立翻译、零新米成分**（PSV 汉化说明文档 §一），不存在 mig/new 之分，故记为 `otv`；空槽记 `empty` |

### 2.1 本模块的字段取值口径（与 W6a 不同处，逐条）

1. **`title_variants[].offset`**：otv 无 R 版 `offset` 概念，本模块取「`:SceneName` 值在脚本文件内起始的 **0-based 字节偏移**」——
   这是真实可复算的定位量，且能把 P03 的 `[StartUp] :SceneName` 与 `SetSceneName` 两个槽区分开。
   `title_jp`/`title_cn` 取**最后一个**标题槽（otv 的**标题槽**无「09 对照/修正表条目」可优先，规则退化为 schema §三.4 的「否则取最后一个」；
   `修正表_otv.tsv` 的 1 条针对的是 `dialogue` 槽，不影响标题取值）。
2. **`lines[].index`**：**全部为 `null`**——otv 源（`台词对照.json`）没有 `index` 列，其唯一行定位键是 `行序`，已记入 `lineno`。
3. **`game_dates[].line_index`**：otv 无 `index`，故此处填**脚本内 `行序`（＝`lineno`）**；由脚本头注释得出的日期其 `line_index` 为 `null`。
4. **`assets[].out_relpath`**：语义本地化，见 §4.2（**这是本模块与 W6a 差异最大的一处，需主代理裁决**）。
5. **`lines[].d14_exception`**：**全部 `null`**——D14 是「不用 R 版正文」的规则，otv 译文本就是独立翻译（与 R 版正文无关），不适用。
6. **`stats.corrections_hit`**：仅 `M01_04` 为 **1**（`修正表_otv.tsv` 1 条，W10b 起生效），其余 30 场景为 0；
   **`stats.d14_exceptions`**：全部 0（D14 不适用于 otv，见 §2.1-5）。
