## 三 演出序列：**可恢复，且已恢复**（96 步）

### 3.1 方法与证据

`op.sob`（Lucifen **SOB0**）的字符串池按**引用登记顺序**登记着全部资源引用：NUL 分隔的字节 run 共 **208** 个，
其中**可解码为 cp932 字符串的 97 条**（头 `SOB0` 1 条 ＋ 资源/控制引用 **96** 条）——其余 111 个 run 解不出合法字符串。**倒序读 ⇒ 推定播放序**（下表为倒序后的步序）：

```
 1–5    cross → rule → BG01 → bg_move → a0 r            ← 交叉淡入 / 遮罩 / 背景右移
 6–10   OP_01(TAK1001) → OP_02(SIN1001) → OP_03          ← 定场三句
11–25   BG63 → bg_move/a0 r → OP_11…OP_16（6 句 6 声）    ← 创世·雪与火
26–43   RULE042 → BG68 → OP_21…OP_28（8 句 8 声）         ← 战祸蔓延
44–65   RULE042 → BG65 → OP_31…OP_3A（10 句 10 声） ← 列国陷落（`bg_move/a0 u` 实际在第 66–67 步）
66–75   bg_move/a0 u → OP_41…OP_44（4 句 4 声，双行条）    ← 骑士与妖术
76–89   BG02 → bg_move/a0 d → OP_51…OP_57（7 条 / 4 声）  ← 片头影片字幕段
90–96   BG01 → bg_move/a0 l → OP_61(SIN1002) → OP_62(YOU1001)  ← 收束框
```

### 3.2 三条**独立**自洽证据（不是「看着顺眼」）

1. **形态不变量**：宽幅背景配横移、纵幅配纵移 —— `bg01/bg63`（1200×600）配 `r`/`l`；`bg02/bg65`（800×1200）配 `d`/`u`；
   `bg68`（800×600＝屏幕尺寸）**无平移**。准确口径：**6 次背景引用 / 5 张背景 / 5 次 `bg_move`**——`bg01` 被移两次（起段 `r`、收段 `l`），
   方向集为 `{r, r, u, d, l}`（**不是 5 个互异方向**），`bg68` 不参与平移；5 次平移与 5 次背景引用**逐次对上**（生成器 G4 把它钉成硬闸门）。
2. **影片画内字幕的时序**：`ot_op2.mpg` 的 10 s 处画内字幕 ≈ `op_51`、30 s 处 ≈ `op_62` ⇒ **51 在 62 之前**，与升序读法一致（若按正序读法则为降序，与该时序矛盾）。
3. **文本框架自洽**：升序读法下首句为 `op_01`「これは“たとえば”の話だけど」、末句为 `op_62`「僕らが君に語るのは、たとえばそんなメルヘン」——
   首尾成框；`op_61` 又逐字节复现 `op_01`（回环）。且末句由 **ヨージ（`YOU1001`）** 念——基本人格收尾。

### 3.3 口径声明（**不得当成已逆向**）

- 字符串表为**栈式登记**（序列号在表中**降序**出现），故「倒序读」是**推定**；正序读法会把整段倒放——已被 §3.2-2 的影片时序否证。
- 表里给出的是**引用序**，**不是时间轴**：每步的**起始时刻 / 停留时长 / 坐标 / 淡入淡出曲线**均**无据**（opcode 未逆向）。
- `a0 r|u|d|l` 中 `a0`＝对象 0、取值＝方向，属**按形态与惯例的解读**（§3.2-1 支持）；`bg_move`/`cross`/`rule` 为控制串，语义按字面。
- 5 个「段组主题」是**内容归纳**（我读文本写的），非源侧记载。

### 5.1 片头影片替换契约（**用户 2026-09-30 裁决「必须做好标注」**）

影片**不是终态**——将来会用一批 **AI 超分 16:9 / 1920×1080** 影片替换。编程组务必按**可替换资产**实现，否则替换时要返工：

| # | 契约 | 理由 |
| --- | --- | --- |
| 1 | **单点引用**：影片只在一处登记（`资源组\审计\序章开场段_清单.tsv` 的影片行，其 `备注` 带 `占位·待替换`），不得把文件名硬编码到多处 | 替换时改一处即可 |
| 2 | **按画布等比缩放**；不得写死 800×600，**也不得依赖 4:3 黑边的几何**（如贴着黑边放 UI、按黑边宽度算坐标） | 换成 16:9 后黑边消失，依赖它的布局会错位 |
| 3 | **时长/内容契约**：替换件须与原片**同内容、同时长**（125.0 s / 177.2 s，允许 ±0.5 s） | 序章停留时间按语音时长推定，影片一变长声画会漂 |
| 4 | **字幕政策随替换重议**：「保留原文」是针对**原版影片画内日文字幕**；若替换件自带中文字幕（或已去字幕），需重新裁决是否还要叠 `op_*` 字幕条 | 避免中日/双字幕叠字 |
| 5 | **替换后必须重跑**：`build_prologue_opening.py`（影片 md5/时长/探针随之变）＋ MCI 可播性探针 | 闸门是防「换了片子忘了改账」的唯一手段 |

> **本段与全流程审计的关系**：`10_全流程资源支撑审计.md` 的结论「缺的是演出编排层数据」对**剧情场景**成立；
