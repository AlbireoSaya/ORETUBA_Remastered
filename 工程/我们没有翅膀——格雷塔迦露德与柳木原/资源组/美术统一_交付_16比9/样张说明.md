## 三、验收②证据（编程组新口径：内容区 PSNR ≥45 dB 或 maxdiff ≤3）

- **落盘前硬断言**（两版均通过）：内容区逐像素 == 输入（A 为整幅 1600×1200；混合为 y∈[56,1136)），`max abs diff = 0`——即「原内容 1:1 不重采样」是构造性成立的，JPEG 误差只发生在编码环节。
- **落盘后再编码误差**（相对输入文件解码像素）：A **PSNR 59.10 dB / maxdiff 7**；混合 **PSNR 59.12 dB / maxdiff 7**。→ 满足 ≥45 dB（maxdiff 7 > 3，按「或」取 PSNR 口径）。
- **阈值已内置为硬断言**（一审打回项-1 修正后）：`verify()` 在 `PSNR < 45 且 maxdiff > 3` 时抛错。
  这条断言同时拦住「偏移未取 8 的倍数」——实测错位时 PSNR 仅 42.40 dB，会硬失败而不是静默放行。

## 四、扩展区色调匹配（tonematch）A/B 实测

算法＝移植 `ISSUE-20260928-02` 的 `tonematch_pass_v2` 核心（缝处 u=0、纯 offset 斜坡 + 亮度残差归零、参考带内移 10 列）。

| 项 | A 无TM → 含TM | 混合 无TM → 含TM |
| --- | --- | --- |
| ramp（缝内参考带 vs 缝外远带，左/右） | 21.54 / 43.26 → **10.86 / 21.07** | 27.31 / 42.87 → **11.31 / 22.84** |
| 缝邻 8 列（含TM vs 无TM maxdiff） | **0**（u=0，不引入新接缝台阶） | **0** |
| 内容区（含TM vs 无TM maxdiff） | **0**（色调匹配只改扩展区） | **0** |
| 横向条纹（逐行亮度相邻差 mean / max） | 0.648/15.37 → 0.781/15.52 ｜ 0.970/10.10 → 1.224/10.75 | 0.638/18.84 → 0.764/19.15 ｜ 1.061/16.26 → 1.313/16.59 |
| 判定 | 色调失配减半、无新台阶（max 台阶不变）、条纹均值 +0.13~0.25 级（亚级） | 同 |

**结论**：tonematch 保留（默认开）。横向条纹均值上升 ≤0.25 级/行（8bit 下不可见级），最大台阶未变。

> 横向条纹**口径**（一审要求补）：对每条扩展区（左条 x∈[0,xl)、右条 x∈[xr,W)）逐行取列均值 → 转亮度（0.299/0.587/0.114）
> → 统计相邻行亮度差 |Δ| 的 mean/max（全高统计，不设窗口）。

## 五、质量如实声明（不修饰）

1. **右缘（砖墙+玻璃）**：AI 延续可用——砖块结构延续自然，接缝处门牌「美空学院正門」按原裁切结束，生成侧接深色玻璃板。
