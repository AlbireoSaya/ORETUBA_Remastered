> **归属**：本目录是**为《我们没有翅膀——格雷塔迦露德与柳木原》工程提供超分美术资源**的工作区，
> 因此放在该工程目录下（与 `资源组\` / `UI组\` / `编程组\` 平级）。素材源是本篇（`ot`）。
> 工具与方法已沉淀为通用 skill：**`.zcode\skills\asset-upscale\`**——本目录不保留脚本副本，
> 复跑一律调用该 skill 的脚本（避免逻辑重复）。

## 一、这一批是怎么做出来的

```bash
# 在工作区根目录下执行
python .zcode/skills/asset-upscale/upscale_batch.py \
    --src "工程\我们没有翅膀——格雷塔迦露德与柳木原\资源组\krkr素材库\ot\chr" \
    --out "工程\我们没有翅膀——格雷塔迦露德与柳木原\素材超分" \
    --model upscayl-lite-4x --exclude "cin" --canvas 1920x1080

python .zcode/skills/asset-upscale/build_compare.py \
    --root "工程\我们没有翅膀——格雷塔迦露德与柳木原\素材超分" \
    --roles "工程\我们没有翅膀——格雷塔迦露德与柳木原\素材超分\roles.json"
```

> 说明：实际首跑时 `in/` 的 `bg` 组是从本篇 247 张背景里**均匀取样 10 张**后留下的；
> 若照上面命令原样复跑 `--src ...\ot\chr` 只会重做立绘组，不会覆盖背景组。

## 四、必须先读的警示

1. **本产物尚未被工程采纳**。资源组《美术规范》§一.1 的 **D1 裁决「全部素材不做放大」仍然有效**——
   采用本目录产物**必须先重新裁决 D1**（理由：放大 2008 年原画会与原生 720p 的 `np` 素材锐度不一致）。
   本目录的定位是「**备选资源 + 实证依据**」，不是已生效的工程输入。
2. **未做全量逐张目视验收**，只做了抽查与模型对照。正式采用前须逐张过一遍。
3. 超分**只恢复可信细节、不创造真实细节**：原图没有的信息（远景文字、细密花纹）会被模型合理猜测。

## 五、模型选型证据

`preview\model_chr.webp` 与 `preview\model_bg.webp` 是选型对照拼图（同一张图 × 4 个模型，
100% 像素裁切；上排：双线性 / 最近邻 / `upscayl-lite-4x`，下排：`digital-art-4x` / `remacri-4x` /
`ultramix-balanced-4x`）。结论：4 款 AI 模型均远优于传统插值；`upscayl-lite-4x` 在赛璐璐线条与
平涂区最干净，故定为主力模型。选型依据详见 `.zcode\skills\asset-upscale\SKILL.md` §四。
