## 五、坑与纪律（本轮新增，**都真踩过**）

1. ★★ **TJS2 正则字面量可「合法模式也抛异常」**：字面量降级为 `new RegExp(pat)` + `RegExp._compile.call(...)`（`tjsInterCodeGen.cpp:2478-2515`；抛点 `tjsRegExp.cpp:245-297`）⇒ 本机 `replace(/[^\x20-\x7e]/g,"~")` 抛异常被吞，**真因（插件链接失败）被假原因 `(non-ascii)` 掩盖了整整一轮**。规避＝白名单表 + `String.indexOf`（已入 §5.11）。
2. ★★ **TJS2 内联字典不接受带引号键**（`"k": v` ⇒ 整份脚本 `execStorage` FATAL）：`--preset states` 的带点键（`fc.state.0001`）曾让**整屏装载失败**，而默认档因键是裸标识符一直"看起来正常"。现发射**逗号式** `"k", v` ＋ 常驻闸门 G-3a。
3. ★★ **`uiThemePalette()` 返回 `0xRRGGBB`，GDI+ pen/brush 要 ARGB**：不补 α ⇒ `drawLines` **不抛错、计数照加、画面零像素**（`current` 环首版 `drawn=2` 却零环，靠**像素测量**抓出）。⇒ **「计数说成功、画面却没有」不是证据**。
4. ★ **复用素材前先量它的 alpha 边**：组名底板复用主图标签件（四边宽渐隐）⇒ 字形核心 5 分位对比度 **1.04:1**；换 444×52 硬边专用件后核心 α≥200 覆盖 99.948%。**「换个件」常比「调几何」更根本**。
5. ★ **验收工具自己也要审**：巡演 `flowclick` 选点不过滤可见性 ⇒ `frag2..frag6` 返回键**从未被点到**，而 9 件「回主干」帧与主干帧**同 md5**；现改为「取第一个**可见**候选」＋ 12 步逐组闭环。**「同 md5 帧＝同一帧副本」必须显式标注**，否则会被读成多次独立取证（E2 已出 `帧到判读对照表.md`）。
6. ★ **金标闸要求「真生成」**：`--dry-run` 不校验金标；`--refresh-golden` **改不到** `PRESET_TABLE` 与 `_schema.md` 金标表（须手改）。
7. ★ **HTML 侧 `attachStates` 无 `state_group` 路径的 `publish()` 曾读恒 false 的 `effHover/effPress`** ⇒ 该类元素 `state_assets` 除初态外一次都不生效（流程图 22 件无组元素全中）——**「带组件的元素都正常」会掩盖这条路零覆盖**。
8. ★ **两端底色实测一致（原「不一致」判断已作废）**：引擎巡演 PNG 是 **RGBA**，`(39,45,59)` 是未计 alpha 的**原始 RGB**（α≈93），合成黑底后显示值 `(14,16,22)`，与 HTML `(14,17,22)` 差 ≤1/255。取色错误来自 `ISSUE-20260927-07` 的 `convert("RGB")` ⇒ **palette note 里的对比度数字算在非显示色上**（真实显示底复算：normal 2.76 / visited 4.33 / 旧 noroute 3.56 / 新 noroute 2.79）。
9. **1028 的判据必须在输出侧**：源侧「边缘比」召回率 8.6%（D 档 6 件真 HARD = 0）；灰度全高平均 `|ramp|` 对**色相**与**分带抵消**失明（`yy_19` 灰度 13.65 / 逐通道 43.0；全库 `ramp≥25` 272 件 vs `ramp_ch≥25` 485 件）⇒ 用「灰度 25 ＋ 逐通道/分带 ≥25」复合门。
10. **`er` 旧口径把「内容自带强梯度」算成填充缺陷**（帧线件内容首列即亮高光线）⇒ 任何正确填充都被判 HARD；修正为「填充区内部、逐带、排除跨缝列」后 geo 通过。
11. **缝条窗口要选对对象**：缝 ±32px 只覆盖 tonematch 效果的 3.1%（窗口内改动 0.58/255、窗口外 18.7 级）⇒ 判色调漂移要看**全宽列均值剖面**。
12. **写 JSON/文本前先验后写**：本轮我又踩到「`io.open(...,encoding=)` 读写会把 CRLF 静默转成 LF」（`Galgame.md` 一度整体变 LF）⇒ 改完立刻 `count(b"\r\n")` 复核；生成器侧已把 `tjs_literal` 的键值转义统一（一审 F-4）。
13. **`_工作` 证据目录会攒出重复的大文件**（本轮 HTML 证据目录里 14 份 1.9 MB 的 `ui_layout.js` 副本 ≈26 MB）⇒ 合并前扫一遍暂存集，只留必要件。
15. ★ **「自证」本身要被审**（HTML 侧一审抓出三类，均已修）：① **锚点会过期**——影子栈脚本把「冻结值」硬编码成上一批的 md5（一跑即失败且**先写后校验**，会把影子栈覆写成新数据）；**冻结锚必须随批更新、先校验后写、且对行尾健壮**（`core.autocrlf=true` ⇒ 盘面 CRLF、金标是 LF 值，按盘面哈希会误判「不一致」，**记录里要同时给两种字节形态**）。② **日志计数不得写死**——变异自证脚本有 8 个模式而日志自称「6 个」（dump 实测 8/8 正确，但**日志低报了覆盖面**）；计数一律从模式表推导。③ **禁止硬编码自证句**——`e3_shell_retention.py` 曾把「某脚本已自证 md5 == …」写进日志（且与影子栈实际值不符）⇒ 自证句必须在运行时读真实值再打印。④ **同族易犯**：「读不到就当通过」（正则只吃一个空格 ⇒ `OK` 行全漏读、基线空表也看不出来）——判据必须「找不到即失败」。
16. **共享 `临时\ui_run` 会串证据**；**一次只跑一个引擎**；`run_e2_fixture.py` 结尾的 `taskkill` 会误杀并发引擎。
