## 六、坑与纪律（本会话新增/强化）

1. **无头 Edge 的 `--window-size` 视口 = `(W−24)×(H−93)`** ⇒ 用 `1920,1080` 会**静默裁掉画布最右 24px / 最下 93px**，量低处元素会得出「没画」的假结论。`w4_html_config_shots.py` 已改为 `1944,1180`。**凡量画布底部/右缘元素都要按此反算。**
2. **收尾改数据一律用「子串级替换」，禁止 `json.dumps` 往返**（本轮把它写成整文件 295 行重排 + CRLF→LF）；**回滚工作树文件前先确认里面没有本批未提交改动**（本轮 `git checkout` 误把同分支上另一位代理的未提交改动一并还原，已用其幂等脚本恢复）。
3. **控制符陷阱**：python 里拼 Windows 路径若用普通字符串，`\t`/`\r`/`\f` 等会被吃成**不可见控制符**（本会话扫出 500+ 处并逐处订正）。**一律用 `chr(92)` 拼或 raw string**；改完文档 `扫一遍控制符`。
4. **派单的「事实前提」与「验收口径」冲突时，先复核盘面再动手**（本会话两次踩到：滑条族 vs 值按钮；我误述的「回想屏四块参差」）。
5. **碰撞判据必须算 `x+w`**（本轮右移碰到的是 x=1110 的角色列，而非只按 x≥1180 检查）。
6. **HTML 复刻自检不得写死素材名/几何**：判断素材或几何的断言必须**从 `ui_layout.js` 数据推**（`_selftest_states.html` 与 `replica.js::runSelfTest` 都踩过），并须补「素材存在性 + 状态区分力（`normal≠hover`）」守卫——**数据把 pressed 与 hover 折叠成同一张图时，断言会恒真**。
7. **镜像纪律**：向主工作树复制前**逐路径查 `git status`**；本次改动集用 `git diff --name-status <上一轮 main> HEAD` 取，**D 项要在主工作树里真的删掉**（不能只拷 A/M）；目标是「内容 == 上一轮 main」才覆盖，否则跳过并报告（`Galgame.md` 因多会话在途长期被跳过）。**合并后必须 `git merge-base --is-ancestor <提交> main` 自检。**
8. **并发会话**：本组作业固定在 `临时\wt-qbicons` worktree 内建 issue 分支 → `--no-ff` 合并 → 逐路径镜像；主工作树常停在他人分支（如资源组 `issue/ISSUE-20260918-06-greta-res-phase2`）。
9. **素材预算 96MB 已近满**（1316 件 / 94.94MB）⇒ 新增件先降色深/精简，需上调须用户裁决。
10. **改屏数据前先查生成器**：`test_gen_sync.py` 的 `GENERATORS/NO_GEN/ACK_UNSYNC/SUPERSEDED` 四表；多处屏已转「手工维护」，别重跑会抹掉成果的生成器。
