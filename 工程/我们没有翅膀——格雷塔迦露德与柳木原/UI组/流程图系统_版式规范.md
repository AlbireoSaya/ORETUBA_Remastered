### 1.3 布局步进（**来自参照作的常量覆盖**）【订正 ①，见 §〇】

`图表加载器_未定名.txt`：`section(dt, ui, vert=250*1.5, step=100*1.5)`；`"chapter" => %[ step:50*1.5, nozoom:true, noshift:true, minimapWidth:2048*1.5 ]`；`"select" => %[ step:100*1.5, vert:300*1.5, boxpads:12*1.5 ]`；`"branch" => section(null,"",,0)`。
⇒ **1.5 是参照作的缩放基准（其设计分辨率 ×1.5）**，**`step` / `vert` 的语义已订正**：

- **`step` ＝ 沿主轴（纵向）的每节点推进量（行距）**：`section/select/fragment/extra` ＝ 100×1.5 = **150**；`chapter` ＝ 50×1.5 = **75**。**它作用在节点自身**（`pos` 累加），与节点宽度无关。
- **`vert` ＝ 同一行内兄弟节点的横向档距**：`section` 类 ＝ 250×1.5 = **375**（select ＝ 300×1.5 = **450**）；**只在数据给 `vdenom>0` 时生效**（`y = vert×(vnumer×2 −(vdenom−1)) \ 2`），整族横向跨度 `vert×(D−1)`、以 0 居中。
- ⇒ **「296 宽的节点为什么不重叠」**：纵向 150 > 节点高 65；横向档距 375（select 450）> 节点宽 296（净间隙 79 / 154）。两条都成立，**不需要**「中心到中心 / 同类不邻接」之类的额外假设。
- `boxpads = 12×1.5 = 18`：**不是文字内缩**——它在 `makeBoxParam`（`scnchart_ui.tjs:2832-2834`）里收缩**画出来的框**（高亮框 / 迷你地图 box 用）。
- 同一行多兄弟靠数据字段 **`nocr`（不推进 pos）+ `vdenom/vnumer`（分档）** 实现，`vclose` 收口；**引擎侧没有自动换行/装箱算法**。
