## 二、每处数字的实测命令与输出

**全部尺寸来自 PNG IHDR 直接解析**（本机 `E:\Tools\Python\python` **无 Pillow**，故不走 PIL；用 `struct` 读 IHDR，字节 16–24 = 宽高 big-endian，字节 25 = 颜色类型）：

```bash
cd "E:/ZCode Workspace/Galgame/工程/我们没有翅膀——格雷塔迦露德与柳木原/UI组"
python -c "
import os,struct
ct={0:'L',2:'RGB',3:'P',4:'LA',6:'RGBA'}
d='krkr/assets/ui';tot=0;n=0
for f in sorted(os.listdir(d)):
    b=open(os.path.join(d,f),'rb').read(33)
    w,h=struct.unpack('>II',b[16:24]);tot+=os.path.getsize(os.path.join(d,f));n+=1
    print(f,'|',w,'x',h,'|',ct.get(b[25]))
print('COUNT',n,'TOTAL_BYTES',tot,'MB',round(tot/1048576,2))"
```

**输出（关键值）**：
- `COUNT 138 TOTAL_BYTES 47231551 MB 45.04`
- `ls -1 krkr/assets/ui/*.png | wc -l` → **138**（与解析一致）

**逐件尺寸**（节选，全量见 §一.2）：`panel_frame 41×17`、`meswin 1586×261`、`nm_frm_b 333×54`、`if_lt 20×8`、`if_tbar 2×8`、`if_lbar 20×2`、`ec5_bg 1200×900`、`tl1_bg1 1800×675`、`sr_01 612×462`、`x_mask_rule000_1280 1920×1080`、`x_mask_rule000_1x 1440×816`、`x_title_bg_1280 1920×1080`、`x_title_logo 723×252`、`x_bg_system 1920×1080`。

**§一.2 表格 vs 磁盘 一致性自证**（脚本解析 markdown 表再逐行比对 PNG IHDR）：

```bash
python -c "
import re,os,struct
txt=open('UI清单.md',encoding='utf-8').read()
i=txt.index('## 一.2 1920 基线资产总表'); j=txt.index('## 二、不可直接使用登记表')
rows=re.findall(r'^\|\s*(\d+)\s*\|\s*\`([^\`]+)\`\s*\|\s*(\d+)×(\d+)\s*\|',txt[i:j],re.M)
d='krkr/assets/ui';bad=[]
for num,n,w,h in rows:
    dw,dh=struct.unpack('>II',open(os.path.join(d,n),'rb').read(33)[16:24])
    if int(w)!=dw or int(h)!=dh: bad.append((n,w,h,dw,dh))
print('rows',len(rows),'| disk',len(os.listdir(d)),'| size_mismatch',bad,'| unique',len(set(r[1] for r in rows)))"
```
**输出**：`rows 138 | disk 138 | size_mismatch [] | unique 138` → **行数 == 目录 PNG 数 == 138，无重名、无尺寸不符**。
