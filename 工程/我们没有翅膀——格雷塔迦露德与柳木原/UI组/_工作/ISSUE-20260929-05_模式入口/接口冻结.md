## C. 「白淡光」与三态的实现口径（**必读，勿误解**）

- **白淡光 ＋ 整体发亮 全靠 `_glow` 图**：三张底光图＝**同一枚柔和白色光晕**的**弱 / 强 / 实底**三档；文字本身三态不变（引擎画字）。
- **按下态**：`_press` 图＝**半透明冰蓝实底胶囊（≈`@palette.accent`）+ 1px 亮边**，**且胶囊整体比 `_off/_over` 的底框下沉 1px**。
- ⚠ **「文字下移 1px」无法实现**（schema 不支持文字逐态位移、`state_group` 只配对图片层）⇒ 以**底沉 1px** 等价表达「按进去」。**如需文字本体位移，须给引擎加「逐态位移」新接口（新裁决）。** 此限制必须写进交接文档。
