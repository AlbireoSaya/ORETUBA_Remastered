# layerExDraw.dll POC · 复现说明

- Issue：`ISSUE-20260927-03`（模块 J）
- 引擎：`工具\krkrz\krkrz_20171225\tvpwin32.exe`（krkrz 1.4.0.8，32 位）——**复制**到本目录 `engine\`，原发行版本体未改动
- 插件：`engine\plugin\layerExDraw.dll`（身份、哈希、来源、许可见 `证据\插件身份.txt`）
- 本目录完全隔离：不引用 UI 组任何既有 tjs / 素材 / layout；`krkr\game\*.tjs` 与 `layout\screens\*.json` 零改动

## 一、怎么跑

```bat
cd /d <本目录>\engine
tvpwin32.exe "<本目录>\game"     :: 主 POC（5 项绘制 + 文字叠加 + 像素锚线）
tvpwin32.exe "<本目录>\game2"    :: 压力 POC（1920x1080，736 节点框 + 735 折线 + 200 箭头）
```

进程约 1.5 s 后由脚本内 `Timer` 调 `win.close()` 自行退出；若窗口残留可 `taskkill /F /IM tvpwin32.exe`。

产物落点：`engine\savedata\`（日志 `krkr.console.log` 为 UTF-16LE；PNG 由 `stageLayer.copyToBitmapFromMainImage` 离屏导出）。
`证据\` 保存了已跑通一次的 PNG 与 stdout 原文，可直接复查，无需重跑。

> 注意：`Plugins.link("layerExDraw.dll")` 的搜索路径是 **exe 所在目录**及其 `plugin\` 子目录；
> 因此 `game\` 与 `engine\plugin\` 各放了一份 dll（`*.dll` 已被 `.gitignore` 忽略，不会入库）。

## 二、日志通道的坑（重跑前必读）

krkr 往 Windows 控制台写日志时对混合编码行会**丢行**。本 POC 因此：

1. 全部日志行强制 ASCII（非 ASCII 用 `~` 顶替，见各 `startup.tjs` 的 `esc()`）；
2. 结尾把整份报告作为**一条** `Debug.message` 再发一次；
3. 另用 `tr -d '\000' < stdout` 抓 stdout——`krkr.console.log` 只在部分运行中生成，stdout 反而稳定。

TJS2 另有两个坑：字符串**没有** `charCodeAt`（用正则 `/[^\x20-\x7e]/g` 替代）；**赋值给未声明变量会抛异常**（一律 `var` 前置声明）。

## 三、插件 API 用法（实测确认，非文档推测）

`manual.tjs` 原文见 `证据\上游源文件\manual.tjs`。

```tjs
Plugins.link("layerExDraw.dll");          // 成功后 Layer 被扩展（实例方法）
var app = new GdiPlus.Appearance();
app.addPen(colorOrBrush, widthOrOption, ox, oy);   // ← 颜色在【第 1 参】，选项字典在【第 2 参】
app.addBrush(colorOrBrush, ox, oy);

layer.drawLine(app, x1, y1, x2, y2);               // 单段直线
layer.drawLines(app, [[x,y], ...]);                // 开放折线
layer.drawPolygon(app, [[x,y], ...]);              // 闭合多边形（描边或填充取决于 app）
layer.drawRectangle(app, x, y, w, h);
layer.drawString(font, app, x, y, text);           // 插件自带文字（本轮未测）
```

- **第 1 参传字典必须带 `color`/`type`（刷子字典）**；只写 `%[width:2]` 会被当成刷子字典而报错。
- 线宽 = 像素，1:1（实测 w=3 → 3 px、w=7 → 7 px）。
- `endCap` 用 `AdjustableArrowCap`：`%[width:28, height:28, filled:true]`；**实测其尺寸会被乘以笔宽**（penW=6 → 头宽 167 px；penW=3 → 83 px）。
- `lineJoin:GdiPlus.LineJoinRound` + `startCap/endCap:GdiPlus.LineCapRound` 实测可用（圆角折线）。
- `GdiPlus` 常量实测：`LineJoinRound=2`、`LineCapRound=2`、`LineCapTriangle=3`、`SmoothingModeAntiAlias=4`（默认即 AA）。

## 五、像素核怎么跑

```bat
cd /d <本目录>\logs
python analyze_png.py            :: 仅用标准库 zlib，无第三方依赖；读 ..\engine\savedata\ 下的 PNG
```

脚本按坐标采样并统计：背景/前景区分、线段中心色、文字带内白/绿像素计数、多边形容alpha 混合值。

> **★ 订正（2026-09-27 一审实测）**：本 POC 进程**不会自行退出**——`Timer`/`win.close()` 未生效，两次 `timeout` 均 `exit=124`（被强杀），stdout 中从无 quitting 行。**复跑请自带超时或手动结束进程**（无 dll 的 Test C 因未建 Window 反而自然结束，故差异只在窗口事件循环）。
