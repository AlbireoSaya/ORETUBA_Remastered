## 二、逐张做法

### 通用版式（6 张一致）
画布 1920×1080。页眉 104 px（标题 + 副标题 + 右上「底：…」+ 图例）；左区 `(28,116,1264,892)` 放实机画面；
右栏 `(1312,116,588,892)` 放规格文字；页脚 `y=1016` 放「对应评估章节 / 接入方 / 参考现有件」。
图例固定为：**橙虚框＝此处生成 ｜ 斜纹＝会被面板盖住 ｜ 青细框＝目标满幅 ｜ 绿虚框＝现有真实素材**。
实机画面缩放比 `k = 1264/1920 = 0.65833`（除示范 2、3 另定），画面左上角 `(28,206)`（垂直居中于左区）。

### 示范 1 · 系统屏专属背景
- **底**：`shot_08_save.png`（save 屏实机，1920×1080，k=0.65833 @ (28,206)）。
- **读的布局元素**：`save.bg_art` `(60,225,1800,675)`、`save.veil` `(60,225,1800,675)`（`@palette.backdrop` 不透明度 150）、
  `save.panel_frame` `(372,219,1176,705)`（九宫格 `l=20,t=8,r=20,b=8`）、`save.footer`（list，`x=645,y=978,item_w=180,item_h=66,gap=45`）、`save.page` `(645,936,630,33)`。
- **占位框算法**：橙框 = `bg_art` 的 layout 坐标 × k + 画面偏移 → 屏幕 `(67,354,1185,444)`。
  标签**不放在框中心**——因为框中部会被「面板遮挡层」压住，故把主标签移到画面上方黑边带（`sbox.y+40`）。
- **「面板会盖住哪些区域」的算法（本题要点）**：取 `panel_frame` 与 `bg_art` 的交集。面板 `y 219–924` 完整覆盖底图 `y 225–900`，
  横向只留下两条竖带：
  - 左带宽 = `panel.x − bg.x` = 372 − 60 = **312 px**
  - 右带宽 = `bg.x + bg.w − panel.x − panel.w` = 60 + 1800 − 372 − 1176 = **312 px**
  两条带高 = `bg.h` = 675。结论：**底图 1176 px 宽的中部整条被盖死**，画什么都不重要。斜纹层即按此交集绘制。
- **另一处**：`save.page`(936) 与 `save.footer`(978) 的 y 已超出底图下沿 900 → 它们在底图之外（画布黑区），标注中写明。

## 三、占位框坐标算法（统一说明）

1. **取数**：`layout/screens/*.json` 的元素 `x/y/w/h`；`kind:list` 元素无 `h`/`w` 时回退 `item_h`/`item_w`
   （`save.footer` 就是这种，第一版脚本因强制要求 `h` 而报 `KeyError`，已改为回退取值）。
2. **映射**：屏幕坐标 `= (layout 坐标 × k) + 画面左上角偏移`，`k = 1264/1920 = 0.65833`（示范 3 为 0.40，示范 2 不映射）。
3. **派生量**（不手填，一律算）：
   - 面板遮挡区 = `panel_frame ∩ bg_art`（示范 1）；
   - 行内卡位 `y = list.y + i×(item_h+gap)`（示范 4）；
   - 主图水平居中 `x = 父元素.x + (父宽 − 图宽)/2`（示范 4）；
   - 面板内缘 = 面板四边内缩九宫格 `l/t/r/b`（示范 6）。
4. **标签避让**：标签位置按「该区域是否会被后续图层覆盖 / 是否有内容」逐个调整——示范 1 主标签移到上方黑边带、
   示范 4 的 11 个行内框改为不填充、示范 5 背景标签移出画面、示范 6 的边框标签与底纹标签分置两处。
5. **溢出防线**：脚本内建 `maxy` 追踪，右栏内容超过 `y=1008` 会打印 `!! WARN 右栏内容溢出 N px`。
   首轮跑出 3 张溢出（示范 2 溢 33 px、示范 5 溢 29 px，另有若干因 `swatches()` 漏更新 `maxy` 而未被捕获），
   已逐条精简文本并把 `swatches()` 的返回值接回 `s.y`/`s.maxy`，**终版 0 警告**。
