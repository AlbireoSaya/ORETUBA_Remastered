## 一、A · 运行态（节点与连线）

### 1.1 节点：元素级新字段 `flow_state`

- 取值（**冻结**）：`"locked"`（未解锁）／`"available"`（可前往）／`"visited"`（已读）／`"current"`（当前）／`"new"`（已解锁未读）。
- 落点：`fc.node.<NNNN>`（image 件）上新增 `flow_state` 字段，**只作数据**（形如声明「本屏样例取该值」）；缺省（不写）＝ `"available"` ⇒ **交付样例不写该字段时外观不变**。
- 表现（**全部走既有机制，不新造绘制能力**）：
  | state | 表现 | 实现 |
  | --- | --- | --- |
  | `available` / `visited` | 无叠加 | — |
  | `locked` | 压暗 | 叠加元素 `fc.node.<NNNN>_dim`（`kind:"rect"`，色 `#000000`，`opacity:110`，矩形＝节点**可见实体面** `x+6, y+8, 284, 48`，`z = 节点z+1`），`vis_flag:"fc.state.<NNNN>"`, `vis_when:"locked"` |
  | `new` | NEW 角标 | 叠加元素 `fc.node.<NNNN>_new`（`kind:"image"`，`asset:"ui/x_ui_new.png"`，`w:50, h:17`，位置**优先照参照作 `(node.x, node.y-12)`**；若越出图表视口或画布则回落 `(node.x+6, node.y+8)`），`vis_flag:"fc.state.<NNNN>"`, `vis_when:"new"`，`z = 节点z+6` |
  | `current` | 高亮环 | **程序化**绘制（krkr `layerExDraw` / HTML canvas）：圆角矩形描边，色 `@palette.node_current`（#D8A83C），线宽 **3**，圆角半径 **16**（与节点底图轮廓同源），矩形＝节点元素矩形内缩 1px；由两端按 `flow_state=="current"` 决定是否画（**不产元素**） |
- ★ 参照作另有「未解锁标题显示 `？？？`」（`图表加载器_未定名.txt:203`）——**本轮不实现**（需运行期改文本，属编程组），登记为缺口。

## 四、两端硬判据（E2/E3 共同，逐条都要能自证）

1. **`links` 的显隐**：`fc_layer != "main"` ⇒ **不画任何连线**（krkr 不进入 `uiFlowLinksDrawScreen` 的连线趟；HTML 不 `drawLinks`）。两端判据同一句话，不得一端画一端不画。
2. **节点叠加件的显隐**由 `vis_flag`/`vis_when` 决定，**两端同判据**：flag 值取屏级 `flags_default`，运行期由 `flow_layer` 动作改写。
3. **`current` 环**：圆角矩形描边 r=16、宽 3、色 `@palette.node_current`、矩形＝节点元素矩形内缩 1px；**两端像素可比**（同一几何公式）。
4. **`locked` 压暗**：rect 叠加（数据元素），**不得**改成改元素 `opacity`（会与既有 opacity 闸门互相干扰）。
5. 命中与绘制**恒同集**（沿用 M06/M08 守卫哲学）：`vis_when` 不满足的元素**既不可点也不绘制**。
