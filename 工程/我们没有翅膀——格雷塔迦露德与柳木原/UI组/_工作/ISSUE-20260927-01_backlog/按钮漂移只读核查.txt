一、结论：按钮本身就是「被漂移的另一半」，它的几何**按旧 `item_text.y=19` 设计**，PSV 换皮轮改的是另一侧

  · `jump` note 自述：`y26 = 与文本区首行中心(≈40)垂直居中`；`replay` note 自述：`y18 = 与首行中心(≈40)对齐`。
    而「首行中心 = `item_text.y` + 行高42/2」⇒ 该等式只在 `item_text.y = 19` 时成立（19+21=40）。
  · PSV 换皮轮把 `item_text.y` 由 19 改成 10（h 173→168），**按钮几何一字未动**（屏级 note 亦自述「几何未改」）。
  · 实机 `shot_29_backlog.png` 量测：首行墨迹中线 182.0 / 373.5 / 567.5 / 758.0 vs `jump` 胶囊中线 198.5
    ⇒ Δ = 16.5 / 17.0 / 15.0 / 16.5px（平均 16.2px）。用户原图独立复量（首行墨迹中线 vs 「跳转」标签墨迹中线）Δ = 10.5 / 10.5 / 9.0 / 10.5px，同向同量级。
  · ⇒ 本轮把 `item_text.y` 复位为 19 后，按钮 **无须改动**即重新与首行同线（**不是按钮漂移，是文本侧漂移**）。

四、`item_buttons[].label` 纵向居中的两端固有差（登记，非 PSV 轮引入）

  · 引擎：`ui_widget.tjs::uiWidgetDrawList` 给按钮标签建文本元素时 `valign:"middle"` ＋ `h = b.h`，
    `ui_theme.tjs::uiThemeLayoutText` 的 middle = `y + floor((h − blockH)/2)`，而 `blockH = 1 × lineH`
    （字号20 × 1.4 = 28）⇒ `y = 26 + floor((29−28)/2) = 26`；字形墨迹又画在行盒顶端
    ⇒ 实机 `shot_29` 「跳转」标签墨迹 canvas y183..202（中线 192.5），比胶囊矩形中线 198.5 高 **6.0px**
    （胶囊可见体 asset 52×29、nine t7/b7 ⇒ 可见体 canvas 187..209，中线 198）。
  · HTML：`.ui-list-item-btn-label` 是 flex `align-items:center`（居中字形内容）⇒ 同布局下旧图实测
    `m06_html_backlog.png` 标签墨迹中线 145.5 vs 胶囊矩形中线 148.5 = **高 3.0px**；引擎同布局 `ui_run_pagescope` 同帧为 **高 6.0px**。
  · ⇒ 两端相差 3px，且两端都比胶囊可见体中心略高（引擎 5.5px / HTML 2.5px）。属 `item_buttons.label` 渲染口径，
    与 `item_text` 无关；本轮禁改，登记为观察项（若要收，需两端同改并出实机对照）。
