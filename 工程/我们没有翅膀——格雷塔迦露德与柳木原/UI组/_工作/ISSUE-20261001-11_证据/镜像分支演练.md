# D-02 证据 · faceIsFileName 镜像分支演练（把「只写逻辑、未走过」的分支真跑一次）

## 为什么要这一跑

`uiTransSettle()` 里有一段「把层上的一次性 font 设置镜像到新前层」——它服务编程组的**内嵌字体兜底**
（`uiStoryFontSetFile()` 只给 `stageLayer`/`primLayer` 置 `faceIsFileName=true`，乒乓交换后新前层会缺位 ⇒ 中文方块）。
但 UI 组自建工程里**没有** `ui_boot.tjs`（那是编程组的文件）⇒ 该分支在 UI 组巡演中**永远不会被走到**；
一审据此判为「逻辑对、未实证」。本跑用**探针演练**把条件造出来：只在**前层**置 `faceIsFileName = true`（＝编程组现状），其余不动。

## 做法（临时演练，未改源码树）

- 复制运行目录 → `临时\ui_run_font`；在该**副本**的 `game\startup.tjs` 里、两层创建之后插入一行
  `stageLayer.font.faceIsFileName = true;`（模拟 `uiStoryFontSetFile`，**只置前层**）。
- 直接启引擎跑巡演约 55 s 后终止；日志存同目录 `镜像分支演练_20261001_2020_krkr.console.utf8.txt`。

### ⚠ 探针改动的原文（**以代码为准**；日志里那句提示写错了）

```tjs
// 插入位置：startup.tjs 的 initialize() 里、stageLayer 与 snapLayer 都创建之后
stageLayer.font.faceIsFileName = true;   // 只给前层（＝编程组 uiStoryFontSetFile 的现状）
Debug.message("[UI][PROBE-FONT] 已在两层置 faceIsFileName=true（模拟编程组现状）");   // ★ 这句提示是「第一次尝试」的残留，与上一行不符
```

**口径澄清（一审复验提出，已核实）**：探针**代码**只给**前层** `stageLayer` 置位（探针副本的 `game\startup.tjs:238`），**日志里那句「已在两层置」是第一次尝试的残留提示、未同步改**（同文件 `:239`）。
判据依据的是**代码行为**：若真给两层都置，`uiTransSettle()` 的条件 `stageLayer.font.faceIsFileName !== true && snapLayer.font.faceIsFileName === true` 永不成立 ⇒ 镜像次数应为 **0**；实测**命中 1 次**，正说明交换后**新前层确实缺标记**（＝编程组现状），随后被补上。
探针副本（worktree 的 gitignored `临时\ui_run_font\`）本轮**保留未删**，便于复核 `:238` 那一行。
- ⚠ 与「编程组现状」的**一处差异**：`uiStoryFontSetFile()` 实际置的是 `stageLayer` **＋ `primLayer`**，本演练**未置 `primLayer`**。因 `primLayer` 从不参与乒乓交换、也不参与镜像判据，该差异**不影响**演练对镜像分支的代表性。
- ⚠ 探针只在**副本**里改：**源码树 `krkr\game\startup.tjs` 里没有那一行**（源码树的转场改动是本次修复本身，用 `git diff 70762c6^ 70762c6 -- krkr/game/startup.tjs` 复核）。

## 结果

| 指标 | 值 |
| --- | ---: |
| 转场交换结算 | 9 次 |
| **镜像命中** | **1 次** |
| 异常 `An exception occured` | 0 |

关键行：

```
20:20:29 [UI][TRANS] 已把 faceIsFileName 镜像到新前层（内嵌字体兜底）
```

**口径**：镜像**命中 1 次**正是设计意图 —— 第一次交换后「原来带标记的前层」变成后层、新前层缺位 ⇒ 补置一次；
此后两层都带标记，`stageLayer.font.faceIsFileName !== true` 不再成立 ⇒ 不再重复（幂等）。
若把该段删掉，本演练的镜像次数应为 0（＝一审指出的「未实证」状态）。

⚠ **本演练不能替代真机验证**：`faceIsFileName=true` 时引擎会把 `face` 当文件路径打开，本演练只为触发**条件与写入路径**；
字体能否真正加载属编程组 `ui_boot.tjs` 的活 —— 真机验收建议编程组在**组装后的游戏**里放 `forcefilefont.txt` 跑一次。
