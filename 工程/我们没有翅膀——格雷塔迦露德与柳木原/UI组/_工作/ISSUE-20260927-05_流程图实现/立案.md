## 一、任务目的（一句话）

把流程图的**版式规范**落成**可运行的产物**：用真实剧情数据生成布局数据，出 1–2 屏真实数据样例，并让 krkr 与 HTML **两端都真画出连线**；番外本轮只放**入口标记**（独立层展开机制留待与编程组对齐）。

**验收标准**

1. `layout\screens\32_flowchart.json` 由**生成器**从真实数据产出（禁止手工摆版），替换现有 3 组样板；
2. 两端（krkr 实机巡演图 / HTML 1:1 复刻）**逐屏目视一致**；
3. 连线由 `layerExDraw` **真绘制**（不是 rect 拼），HTML 侧有**同判据**实现；
4. 九道闸门全绿（`verify_ui` 七项、`test_gen_sync`、点击可达、状态目标、快捷条、字段粒度、资产引用）；
5. 把**没有的运行态**（悬停/选中/解锁/当前节点）如实登记，不编造。

## 四、已知风险（开工前登记）

1. **HTML 侧连线无先例**——`replica.js` 目前完全没有连线渲染，属新实现，两端一致性风险最高；
2. **`layerExDraw` 合规与 Win7 未闭环**——取自本机商业 Steam 版（推断即上游未改版），须随包附许可文本；Win7 SP1 未实测；
3. **集成三坑**：dll 放 `krkr\runtime\plugin\`、**不塞进 XP3**、`run_*.bat` 只在 `runtime` 不存在时复制 ⇒ 新增 dll 须补强制刷新；
4. **`ui_flow.tjs` / `ui_flow_data.tjs` 与屏数据脱节**（旧 40 函数引用已被 M34 删除的 `flow.*` 元素）⇒ 本轮需决定「重写 vs 回收」，并在两处产物命名上保持两端一致；
5. **素材预算 94.94 / 96 MB 近满**——新增件先降色深/精简，需上调须用户裁决；
6. **数据本身的可信度折价**：`pairing_verified` 仅 1 项为 true（分支落点多数未确证）、`entry_after` 全为 null（番外接入位置无原作证据）⇒ **图上不得编造配对**；
7. **`05_章节总表.tsv` 无官方列义文档**（列义系数据推断）。

## 五、本轮明确不做

- 番外**独立层的展开机制**（点开才展开）——需接运行期状态，属编程组职责边界；
- 50 分歧点的**逐选项落点连线**——只标分支底座 + 右侧信息栏列选项；
- 节点**运行态**（未解锁/已读/可去/当前）的新状态机制——一律用既有机制（`state_assets`/`vis_flag`/`item_variants`），不新造第二套；
- 缩放/平移/付箋/回放窗的**交互逻辑**（属编程组），本层只保证静态几何 + 态图 + 热区。
