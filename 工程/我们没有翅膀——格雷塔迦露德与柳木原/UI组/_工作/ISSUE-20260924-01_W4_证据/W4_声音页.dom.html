操作：点击画面推进台词（打字机逐字显示）｜空格/Enter 推进｜ 按住 Ctrl 快进｜A 自动播放｜H 隐藏/恢复窗口｜ Esc 返回上一层／退出（浮层打开时先收起浮层）｜Backspace 返回上一屏。
画面右键：呼出 9 图标功能浮层（快速存档 / 快速读档 / 快进 / 返回上一选项 / 存档 / 读档 / 设置 / 隐藏对话框 / 重复语音）；浮层内左键点空白处或再按一次右键收起。 与实机（krkr 侧 startup.tjs 的 toggleSysIcons()）语义一致：仅对话框屏支持。
系统条 9 键：快速存档 / 快速读档 / 快进 / 返回上一选项 / 存档 / 读档 / 设置 / 隐藏对话框 / 重复语音 —— 全部可点击（与右键浮层的 9 图标同源）。
演示背景：对话框 dynamic:"story_background" 层由真实素材占位填充，当前使用 （当前屏无 story_background 层）；该层在 krkr 侧由编程组按当前场景源代号填入 1:1 剧情背景， 本页仅为占位演示，非剧情素材。
