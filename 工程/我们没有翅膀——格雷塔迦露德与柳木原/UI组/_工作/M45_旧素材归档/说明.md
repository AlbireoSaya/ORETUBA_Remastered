| 素材 | 引用处（`20_sysmenu.json`） | 是否被他屏引用 | 处置 |

| `ui/x_ui_backlog_bg.png` | `sm.bg`（满幅底，z=0） | **是** —— `22_loading.json`（`ld.bg`）同时引用 | **不归档、不移动、不删除**（共享件） |
| `ui/x_ui_btn_l_off.png` | `sm.item1..8`（8 个菜单项底，z=20）、`sm.back`（返回键底，z=20） | **是** —— `21_confirm.json`（`cf.yes`/`cf.no` 底图与 `state_assets.normal`）、`23_save.json`、`24_load.json` 同时引用 | **不归档、不移动、不删除**（共享件） |

核查命令（**逐个引用点全库复核**，非抽样）：


## 三、色板（`layout/palette.json`）**未改**

按派单要求：**色板是共享资源，删键有风险**。本次**未删除任何色键**。
`sysmenu` 屏引用的两个色键均被大量他屏共用（实测）：

`layout/palette.json` 的 md5 与改动前一致。

## 四、动作 `open_sysmenu` **保留不动**（本屏废除不等于动作废除）

用户口里的「药丸按钮系统」＝ M37 起落地的**右端竖排快捷条**（一排独立圆形 icon + 名称药丸）。
`open_sysmenu` 的语义自 M2 起已重定义为「**展开竖排快捷条（不钉住）**」，
**不是**「打开传统系统菜单屏」——本次**只清理「`open_sysmenu` → `sysmenu` 屏」这条早已移除的映射的残留注释**
（改成「该屏已废除」），**动作实现一字未动**（`ui_screens.tjs` 的 `uiQuickbarOpen` / `UIScrQuickToggleAct`、
`replica.js` 的 `expandQuickbar()` / `case 'open_sysmenu'` 全部保持原样）。
