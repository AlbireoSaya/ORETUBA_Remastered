## 一、可用图数据（三份，均已就绪）

### 1.1 `资源组\剧本\spine.json`（114,773 B）

顶层：`version/generated/module/basis/acts(11)/excluded(32)/side_stories(53)/branch_points(50)/reconciliation(15 字段)`。

- **`acts[]`**（11 项）键：`act/name/source/scenes/line_count/note/basis`；`scenes` 是**场景 id 字符串数组**。11 幕合计 **627** 个（去重后 627）、`line_count` 合计 **86,245**。例：act 1「前奏诗·框架剧与四短篇」`source:["otp"]`、22 场景、3531 行。
- **`branch_points[]`**（50 项）键：`scene_id/source/script/route/in_spine/option_count/choices/candidate_targets/pairing_verified/note`。
  - `choices[]` 键恒为 `text_jp/text_cn/target`（全文件 **156** 条；`target` 非 null 仅 **41** 条，集中在 `np_start_oretuba`(34) 与 3 个 otp 分支）。
  - `candidate_targets` 是**脚本名**（**无源前缀**）数组，长度分布 `{2:26, 3:11, 1:12, 26:1}`，共 **123** 条；带前缀后可解析 114 条到 acts 场景、9 条不解析。
  - `in_spine` 46 true / 4 false；`pairing_verified` **仅 1 项 true**（`np_start_oretuba`）。
  - `route` 13 种。
- **`side_stories[]`**（53 项）键：`scene_id/source/script/group/title_jp/title_cn/next/entry_after/entry_after_basis/entry_suggestion/note`；`group` **6 种**；`next` 是脚本名数组（**合计 25 条**）；`entry_after` **全为 null**（即：番外的接入位置**无原作证据**，只有 `entry_suggestion` 建议）。
- **`excluded[]`**（32 项）**全部是 `otp`**（D15 原型版）。
- **`reconciliation`**：`source_scene_total 712 = acts 627 + excluded 32 + side 53`，`duplicates=[]`，`coverage_ok=true`；`choices_total_in_spine 147`。
- **全文件 `scene_id` 712 个**，命名 `<源前缀>_<script>`，前缀 `ot 367 / ota 172 / otp 59 / otr 55 / otv 31 / np 28`。
- **★ 没有统一的全局边表**：有向关系只有三处 —— `side_stories[].next`(25)、`branch_points[].candidate_targets`(123)、`choices[].target`(41)；`acts[].scenes[]` 只有序无 next。

## 三、可复用机件（事实）

- **状态机制**（`layout\_schema.md`）：`flags_default`/`reveal`/`attach`/`vis_flag`/`vis_when` 在 §四（`:83` 起，`:95-99` 字段表）；`state_assets` 在 hit 块 `:386-391`（回落链 `pressed→hover→normal→asset`，`:261`）；`item_frame.state_assets`（逐项三态）`:256-261`；`item_variants`（`n/N` 差分）`:268-317`；`visible_default` 铁律（靠 flag 控显隐必须 true）`:109/:507/:521`。
- **滚动**：`list.scroll`（`_schema.md:193/213/475`；krkr `ui_widget.tjs::uiWidgetListPage`/`uiWidgetDrawList`，`ui_screens.tjs::UIScrPage`；HTML `replica.js::buildList`）；鼠标滚轮 `startup.tjs::onMouseWheel` → `page_prev/page_next`。
- **流程图的滚动是自研 y 偏移**（非 list）：`ui_flow.tjs::uiFlowBuildScroll/uiFlowApplyScroll/uiFlowScrollToCursor/uiFlowPage`（M18 后单屏总览已退化为 no-op）。
- **`setZoom` 是窗口级画布缩放**（`startup.tjs:185 setZoom(2,3)`，1920×1080 → 客户区 1280×720），**不是内容缩放**；引擎**未见 per-layer 缩放 API**（`.zcode\skills\kirikiri-unpack\引擎工作原理.md:40` 记 `Layer.affineBlend` 等旧物已删；`:280-289` 的 Layer 绘制 API 只列 `colorRect/fillRect/drawText`）。缩放控件 `fc.zoom_*/fc.shift_*` 现为**静态摆放**（逻辑留给编程组）。
- **`layerExDraw` 的 `setTransform` 在 POC 中确认存在**（见 `ISSUE-20260927-03`）——即"插件层的变换"可用，与"屏内容整体缩放"不是同一件事，设计时须区分。
