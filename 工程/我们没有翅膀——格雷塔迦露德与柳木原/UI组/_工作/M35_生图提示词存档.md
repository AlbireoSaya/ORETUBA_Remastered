# 生图提示词存档（**实际发出的原文**，可直接复制）

> 由脚本 `工具\lyai-image-api\dump_prompts.py` 从生成器源码直出，**非手抄**。

---

## 0. 调用参数（三批共用）

```http
POST https://api.lyaiapp.com/v1/images/generations
Authorization: Bearer <key>
Content-Type: application/json
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36
```

```json
{
  "model": "gpt-image-2.5-1k",
  "prompt": "<见下>",
  "size": "1536x1024",
  "n": 1,
  "background": "transparent",
  "output_format": "png",
  "response_format": "b64_json"
}
```

- **没有任何图片输入**：纯文生图，无参考图、无 image 参数
- `User-Agent` 必须伪装浏览器，否则 Cloudflare 返回 `error code 1010`
- `background:"transparent"` 单给**不生效**；真 alpha 靠 prompt 里的**指令式**要求
  （本工程实测：描述式 `transparent around it` → RGB；指令式 `Transparent background with a real alpha channel.` → RGBA）

## 1. 中文 3 组（最新一批 · 像素算式级）

### 1.1 主模板

```text
A PNG image containing exactly the Chinese characters "{中文}" arranged horizontally, in a clean bold Chinese gothic typeface with frosted ice-glass lettering filled by a pale ice-blue to near-white gradient (#DCEBFB to #FFFFFF) and a thin cyan-blue edge (#7CB7FD). PIXEL SPECIFICATION (follow exactly): each Chinese character occupies EXACTLY 48 by 48 pixels; the horizontal gap between two adjacent characters is EXACTLY 4 pixels; therefore the {n} characters together occupy EXACTLY a pixel rectangle of {W} by 48 given by {公式}. Every character has the same height, the same width, the same stroke weight and the same baseline, evenly spaced on one horizontal line like a monospaced grid. The characters read exactly "{中文}" and nothing else — do not substitute, add, reorder or omit any character. Behind the characters: {羽毛描述}. Around the characters: {光晕描述}. Transparent background with a real alpha channel; everything except the characters, the faint glow and the small feathers is fully transparent and empty. NO button, badge, chip, pill, tag, label, card, plate, banner, panel, frame, border, rectangle or rounded rectangle of any kind behind or around the characters.{L2..L5 追加段}
```

### 1.2 变量取值（照表替换）

| 中文 | n | 目标矩形 | 公式 |
|---|---|---|---|
| 开始游戏 | 4 | **204×48** | `(48×4+4×3)×48 = 204×48` |
| 继续游戏 | 4 | **204×48** | `(48×4+4×3)×48 = 204×48` |
| 读取存档 | 4 | **204×48** | `(48×4+4×3)×48 = 204×48` |
| 流程图 | 3 | **152×48** | `(48×3+4×2)×48 = 152×48` |

| 画廊 | 2 | **100×48** | `(48×2+4×1)×48 = 100×48` |
| 离开游戏 | 4 | **204×48** | `(48×4+4×3)×48 = 204×48` |

### 1.3 三组的羽毛 / 光晕描述

| 组 | 羽毛 | 光晕 |

| 1. 羽毛轻·光晕弱 | `only a FEW very small faint white feathers` | `a very faint soft white glow` |

### 1.4 递进加强段（L1 为空；失败时依次追加，最多到 L5）

**L1**：（不追加）

**L2**：

```text
Re-read the pixel specification above: every Chinese character is EXACTLY 48 by 48 pixels, the horizontal gap between adjacent characters is EXACTLY 4 pixels, and the total ink area is the exact pixel rectangle given above. Nothing may exceed that rectangle.
```

**L3**：

```text
The whole word occupies exactly that pixel rectangle, left-aligned, with no extra space at either end beyond the specified rectangle. All characters share the same baseline, the same cap height and the same stroke weight.
```

**L4**：

```text
Draw the characters on a strict uniform grid: character i occupies columns [i*(48+4), i*(48+4)+48) of the specified rectangle.
```

**L5**：

```text
STRICT FINAL: the rendered word must measure exactly the specified pixel rectangle. No scaling, no letter-spacing drift, no extra characters, no missing characters.
```

## 2. 英文 3 组（B17 批次 · 已通过自动判定）

### 2.1 主模板

```text
A single English word spelled exactly "{WORD}" in capital letters, in a clean bold geometric sans-serif typeface, FLAT OPAQUE SOLID lettering only, {字色描述}, with HARD CLEAN SHARP edges and anti-aliased edges only. The letters are completely opaque and flat. Absolutely NO glow, NO halo, NO outer light, NO bloom, NO drop shadow, NO blur, NO soft falloff, NO aura, NO sparkle, NO background panel, NO box, NO rectangle, NO plate, NO shape, NO gradient wash behind the letters, NO texture behind the letters; the surrounding area must be 100% fully transparent and completely empty. Spell the word exactly as given, with no extra words, letters, symbols or decorations
```

### 2.2 三组字色

| 组 | 常规态 | 悬停态 |
|---|---|---|
| A | `filled with one flat uniform opaque pale ice-blue colour #DCEBFB` | `filled with one flat uniform opaque brighter ice-blue colour #A8D2F6` |
| B | `filled with a smooth vertical gradient from ice-blue #A8D2F6 at the top to near-white #E8F4FF at the bottom` | `filled with a smooth vertical gradient from deeper ice-blue #6FB0F0 at the top to pure white #FFFFFF at the bottom` |
| C | `filled with opaque near-white #F2F8FF and edged with a thin crisp darker ice-blue outline #5E9FE0` | `filled with pure opaque white #FFFFFF and edged with a thin crisp deeper blue outline #3D86D8` |

### 2.3 递进加强段（L1..L5）

**L1**：

```text
The image must contain ONLY the letters themselves. Do NOT draw any button, badge, chip, pill, tag, label, card, plate, banner, panel, frame, border, rectangle, rounded rectangle or any other shape behind or around the letters. Do NOT draw a UI element of any kind. Do NOT draw any outline around the word as a whole. The area around and between the letters is fully transparent empty space. NO glow, NO halo, NO outer light, NO bloom, NO drop shadow, NO blur, NO soft falloff, NO aura, NO sparkle, NO texture, NO gradient wash behind the letters.
```

**L2**：

```text
Think of a type specimen sheet: each letter floats alone in empty space with nothing else around it. The canvas is completely empty except for the letter strokes. If you were to fill the whole image with a colour, only the letter strokes would be visible.
```

**L3**：

```text
Operationally: type the word in a plain text editor, screenshot only the glyph pixels, then use a magic-wand background eraser on everything that is not a letter stroke. The result is exactly what is wanted. Any rectangle of any kind, of any opacity, is a critical failure.
```

**L4**：

```text
The output is equivalent to an image whose alpha channel contains ONLY the glyph shapes: alpha is non-zero on letter strokes and exactly 0 on every other pixel. No capsule, no plaque, no slab, no strip, no underline, no divider, no watermark.
```

**L5**：

```text
STRICT FINAL REQUIREMENT: every pixel that is not part of a letter stroke must have alpha = 0. Only letter strokes may be opaque. Do not fill any region behind the word. Do not add any background, backdrop, backplate or container.
```
