## 0. 结论摘要

- 两屏的**全部美术**来自两张 AI 生图满幅底图：`ui/x_gen_gallerypage.png`、`ui/x_gen_fragpage.png`（各 1920×1080，RGB）。JSON 里除这两张外**没有任何面板/边框/图标素材** —— 面板、边框、标题字、雪花/冰晶装饰、羽毛纹全部烘焙在底图里。
- 统一风格：**冰蓝霜白、半透明磨砂玻璃面板 + 冰晶/雪花闪点 + 大羽状/绸带波浪纹 + 柔光边缘**。底图基调近白（#F1F7FC），向左下过渡到淡冰蓝（#E3EDF9），高饱和强调色落在 #71AAF3–#9DCDFB 区间的冰蓝。
- 面板：**圆角**，大框半径实测 ≈ 24–30 px、预览大框 ≈ 20–24 px、Fragment 小格 ≈ 15–17 px（均在 1920 画布实测像素上）。边框是**约 2–3 px 的青色细线 + 约 8–12 px 的外发光晕**（不是硬描边）。
- 字体：无专属字体文件，走系统回退链；底图里的 "Fragment" 标题是**栅格化美术字（衬线风格）**，不是可复用字体。引擎绘字用回退链 `微软雅黑/Microsoft YaHei/黑体/SimHei/宋体/SimSun/MS Gothic`。
- **风险**：`palette.json` 仍是旧暗色主题值且 `verified:false`（如 `text_menu #E8E8F0` 近白、`highlight #3A5A9A`），直接画在霜白底图上会**严重低对比**。新风格锚点应据此重建色板（见 §4）。

## 4. 形状与纹理特征（实测）

### 4.1 形状
- **面板一律圆角**，无尖角、无切角。
  - 左侧大选择框：半径 ≈ **24–30 px**（1920 画布）
  - 右侧预览大框：半径 ≈ **20–24 px**
  - Fragment 小格：半径 ≈ **15–17 px**
  - 源图半径约为此值 ÷1.1483（大框 ≈21–26、预览 ≈17–20、小格 ≈13–15）
- **边框**：不是硬 1px 线，而是「**≈2–3 px 青色细线 + ≈8–12 px 柔光外晕**」。
- 每个面板的**左上角有一道斜向高光扫过**（磨砂玻璃斜光），左下沿有一道**青色外发光**。

### 4.2 纹理与装饰
- **大羽状 / 绸带波浪纹**：背景左右两侧有半透明的巨大羽毛状/绸带状弧线。最蓝处 `#9DCDFB` / `#7AB2F1`，亮处近白 `#F9FAFE`。
- **冰晶闪点 / 四角星**：简介条左端每行一枚四角星项目符号（`#8CB9F7`）；名条左端一枚；Fragment 各格左上有一小簇雪花/冰晶纹理。
- **渐变**：背景近白（上/右）→ 淡冰蓝（左下）；面板近白顶 → 冰蓝底；名条左深右浅。
- **光晕**：面板下沿与左沿有柔和青色外发光；无强烈内阴影、无投影黑边。

## 7. 与《交汇协奏曲》UI 设计语言的差异清单

《交汇协奏曲》设计语言（`工程\交汇协奏曲\作品skill\SKILL.md:212`）：节点块是**纯色圆角矩形**，`section/off` 浅蓝填充、`section/on` 白底蓝描边；分隔线 1233×2；分支块 65×65 圆角方块 —— 即**扁平浅底 + 青色 #22B8F0 强调 + 圆角方块 + 几何图标**。

| 维度 | 交汇协奏曲 | 本作（新锚点） |
|---|---|---|
| 底色 | 扁平纯色浅底，无渐变/无纹理 | 冰蓝霜白**渐变底** + 大羽状/绸带波浪纹 |
| 面板材质 | **纯色实心**填充 | **半透明磨砂玻璃**，有斜向高光扫过 |
| 面板形状 | 圆角矩形（小圆角，几何感强） | 圆角矩形但**半径更大更柔**（大框 24–30 px），带外发光 |
| 描边 | 白底蓝描边（实线、几何） | 2–3 px 青蓝细线 **+ 8–12 px 柔光外晕** |
| 强调色 | 单一青 **#22B8F0**（高饱和、偏青绿） | 冰蓝族 **#71AAF3 / #90BDF5 / #9DCDFB**（偏紫蓝、低饱和、更淡） |
| 装饰元素 | **几何图标**、方块、直线 | **冰晶/雪花四角星闪点 + 羽毛/羽状纹**，无几何图标 |
| 光效 | 扁平无光效 | **内高光 + 外发光晕**，柔光为主 |
| 文字色 | 深色文字压浅底 | 标题深蓝 **#2E6BB4**，正文需另定 |
| 整体气质 | 现代扁平、理性、几何 | 空灵、霜雪、柔光、梦幻 |

一句话差异：**《交汇协奏曲》= 扁平几何 + 高饱和青；本作 = 霜白磨砂玻璃 + 低饱和冰蓝 + 冰晶雪花柔光。**
