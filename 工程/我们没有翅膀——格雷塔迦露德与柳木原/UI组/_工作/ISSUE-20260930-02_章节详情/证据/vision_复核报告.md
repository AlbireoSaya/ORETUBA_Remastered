- **协调度**：体积合适（41px / 1920 画布 = 2.1% 宽；对「说明」槽 421×150 是 10%×27%），不显大也不显小；作为点击热区 41px 已在舒适下限附近（建议视觉不变、热区撑到 ≈48px）。

## 2. 三态是否一眼可辨 —— **部分达标（press 达标；off/over 偏弱；1px 下沉看不出）**

**证据（3× 对照图 E1 + 单件像素）**

- **off → over**：填充 (230,240,253,α237) → (213,230,249,α250)，RGB 差仅约 (17,10,4)；真正的线索是**外圈由灰 (172,185,206) 变成鲜蓝 (151,193,238)**。注意：按亮度算，over 的填充反而**比 off 略暗**（≈238.5 → 227），所以"提亮"这个描述名不副实，实际变化是"变得更蓝/更饱和"。在 3× 图上两者**能分辨，但差异偏细**，属于"要靠对比才看得出"的档位，不是一眼可辨。
- **off → press**：完全可辨、无歧义——盘面变为实心蓝 (167,203,241,α253)、字形变纯白 (244,248,255)。这是三态里唯一"扫一眼就知道"的一档。
- **「按下整体下沉 1px」**：**量得出来，看不出来**，如实说明——
  - 资产：off 的 alpha 外框 y=1..41，press 的 y=2..42，x 范围同为 1..41 → **纯平移 1px、尺寸不变（盘径都是 41px）**。
  - E1 的 3× 图上该位移放大为 3px：off 盘顶行 ≈y=37–39、盘底 ≈159；press 盘顶 ≈41–42、盘底 ≈162 → 底边差 3px、顶边差约 4px，与"3× = 3px"相符；对照图里那条橙线就是 off 的基准行（y=40）。
  - **但我在 3× 图上看不出下沉**：三颗盘横向相隔 184px、没有共用基线，3px 的纵向错位没有参照物可依；到实机 1:1 时下沉只有 1 个真实像素，**基本不可能被感知**。所以这一档的"反馈"实际全靠颜色，1px 下沉应视为实现细节而非可见反馈。
- **未覆盖**：E1 对照图的底色是**深蓝 (28,41,57)**，而实机里按钮坐在**中亮色槽底 (140,152,165)** 上；亮底上 off 的淡色盘不如在暗底上跳，**实机 off/over 的差距很可能比 E1 图更小**。而本批**没有实机 over/press 截图**，无法直接验证实机 hover/按下观感（见"未覆盖"节）。

## 3. 浮层开启态观感 —— **底板达标；文字可读达标；层次与留白不达标**

**（a）底板 x_ui_gal_cell_on 拉大后：无拉伸变形/糊/接缝，边框四边均匀 —— 达标**

- 边框实测**恰好 2px、四边同色 (121,175,231)、连续无缺口、四角为直角**：
  - 上 y=214,215 → x=340..1579 连续 1240px 无缺口；下 y=864,865 同；左 x=340,341 → y=214..865 连续 652px；右 x=1578,1579 同。
  - 四角裁切图：TL/TR/BL/BR 均为干净的 90° L 形，半径 <1px。
- 源件 `x_ui_gal_cell_on`（291×166）同样是**2px 边框 + 直角 + 内部 (50,72,98)**，且带约 6px 略亮的内部倒角带。渲染面板：边框 2px、(121,175,231)、倒角带约 6px（x=342..347 由 (68,99,131) 渐到 (53,76,102)）、内部 (50,71,97)。→ **边框与倒角按原尺寸保留、只有内部被拉伸**，等于做对了 9-slice；1240/291=4.26×、652/166=3.93× 的拉伸下边框仍是 2px，故**两边不匀、变形、糊、接缝一概没有**。
- 内部填充均匀：沿 y=750 与 x=1000 采样全为 (50,71,97)±2（那 ±2 是 PNG 抖动，肉眼不可见），**没有多余的内层矩形或亮带**。我特意找过 1px 级台阶，最陡也只有 2–3 个色阶，属抖动噪声，不构成接缝。

**（b）白字+黑描边在 #324862 上的可读性 —— 达标**

- 白芯纯 (255,255,255)，底 (50,71,97)（即 #324761，与目标 #324862 同族）→ 对比度 **≈9.4:1**（远超 WCAG AA）；黑描边为纯 (0,0,0)，厚约 2px。可读性没问题。

**（c）标题与正文的层次 —— 偏弱**

- 字号确实**两行相同**：逐字步进 25.2px（`章节标题`，x=371..471）与 24.3px（`章节简介全文`，x=371..516）；两行白芯字高都 ≈23px。
- 粗细有差但很细：取**同一个笔画**（"节"字"艹"的横，两行都是 x≈396..419 的 22px 长横）测垂直厚度 —— **标题 3px，正文 2px**。即标题略粗、正文常规，靠"字重 + 位置"区分成立，但只差 1px，**层次感弱**。
- 正文的"白肉"偏瘦：正文行内黑像素:白像素 ≈ **3.5:1**（标题约 1.1:1），说明 2px 黑描边在 24px 常规字重上占掉了相当大的比例，字面略单薄（仍可读，不算糊）。

**（d）留白/内边距 —— 不达标（严重不对称）**

- 实测内边距：**左 23px（内边 348 → 墨迹 371）、上 32px（内边 216 → 墨迹 248）、右 1062px、下 533px**。
- 文字块外接矩形仅 146×82px，面板 1240×652px → 文字块**只占面板面积约 1.5%**，约 98% 是空底。左/上尚可，右/下完全空旷，观感"像没做完"。

**（e）面板位置与大小 —— 位置达标，尺寸偏大**

- 完全居中：x 340..1579（中心 959.5 ≈ 960）、y 214..865（中心 539.5 ≈ 540）。
- 占画布 64.6%×60.4%，四周留白 左 340 / 右 340 / 上 214 / 下 215px → 呼吸空间充足、位置得体。
- 但对"章节标题 + 章节简介"这个体量，1240×652 明显偏大（内容只填了左上角）。

**（f）另发现：浮层内没有任何关闭控件**

- 扫过面板内部（x=1000..1575, y=220..360 及全面板），除两行文字外**没有任何字形或按钮**（仅右边框倒角带的 25 个像素）。观者在浮层上找不到"关闭/×"，只能去点右栏那颗已被压暗的加号。这是开启态最需要补的一点。

## 4. 浮层关闭态：右栏其余部分是否被动到 —— **达标（无副作用）**

- 逐点比对开/关两图，在 **x=1600..1920、y=150..1000**（覆盖加号按钮与右栏右侧约 40% 区域）共 30388 个采样点：open/closed 亮度比 **mean 0.4106、min 0.405、max 0.414，|比值−0.41|>0.06 的离群点 0 个**。
- 即：右栏只是被**均匀压暗到 41%**，布局/内容**逐点无变化**；浮层关闭后右栏恢复原样。除浮层消失外，右栏没有被动到。
- 佐证：加号按钮本身也只被压暗——(1824,646) 关闭态 (167,203,241) → 开启态 (69,84,99)，比值 0.413/0.414/0.411，与全场一致。

## 6. 遮罩强度 —— **达标**

- 全场**均匀乘法压暗 0.41**（= 黑色遮罩 α≈0.59）：采样点 (100,1000) 0.409、(960,60) 0.410、(1900,60) 0.410、(1880,1000) 0.410、(1560,950) 0.411、(1900,540) 0.414 —— 无渐变、无方向性。
- 背后内容仍然认得出：流程图节点、右栏三个槽、左侧黄色椭圆（压暗后变橄榄色 (238,238,144)→(98,98,59)）都清晰可辨；面板本身因近乎不透明（填充 α≈0.97）加 2px 亮蓝边框，与背景分开得很干净。既突出浮层又看得见背后 → 强度合适（若想更聚焦可再压到 0.35 左右，但当前值不算问题）。
- 无投影：面板边缘外 1580→1650 比值恒为 0.41，没有 drop shadow；靠亮边框做分离，够用。
- **附带发现**：遮罩把**加号按钮也一起压暗**（按钮在遮罩之下，非之上）：开启态下按钮盘 ≈(94,98,104) vs 周围 ≈(57,62,68)，亮度差仅 ≈37，环只剩 ≈15 → 开启态里那颗加号是一枚**很淡的浅色盘**，读不出"可点的控件"。

## 7. 最想改的 1–3 点（按影响排序）

1. **给浮层补关闭控件（影响最大）**。改什么：在面板右上角加 × 圆形按钮（用现成 pbkick/plusbtn 同色板），或把右栏那颗加号在浮层开启时**提到遮罩之上**（不参与 0.41 压暗）并在开启态切成"×/收起"图标。原因：目前开启态面板内零控件、那颗加号又被压到 41%，观者找不到关闭路径。
2. **收紧面板尺寸 + 左右内边距转对称**。改什么：面板从 1240×652 缩到约 720×360（或高度随正文自适应，宽度按最长文本行定），并让内边距左右一致（现在左 23px / 右 1062px）。原因：内容仅占约 1.5% 面积，空得　像未完成；同时正文建议用中黑、或把黑描边由 2px 降到 1px，让 24px 常规字重的"白肉"更饱满（现正文 3.5:1 的黑白像素比偏瘦）。
3. **加号按钮两处微调**：(i) 把它与「说明」标签的**光学中心对齐**（现在比标签中心低 13px）；(ii) 把外圈描边加深到接近 pbkick 的 (146,159,183) 且 α 提到 255（或干脆不要用 41px 降采样件、按 44px 画布原生重绘 2px 描边），补上小尺寸下丢失的边缘干脆度。可选把热区撑到 48px 而不改视觉体积。

**是否达到可给用户看的程度**：底板、遮罩、关闭态无副作用、文字可读性都已合格，**可以给用户看**；但建议**先把第 1 点（关闭控件）改掉**再交用户过目——否则用户的第一反应大概率是"这浮层怎么关"。第 2、3 点属观感优化，可同批改也可留待用户裁定。
