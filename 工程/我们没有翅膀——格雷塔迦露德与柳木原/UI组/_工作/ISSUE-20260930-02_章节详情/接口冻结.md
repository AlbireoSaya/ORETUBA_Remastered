## 五、超框省略号（M2，机制，两端同判据 + 三处实现）

**现状（实测）**：`krkr\game\ui_theme.tjs::uiThemeWrap` 在行数超过 `max_lines` 时是
`while(out.count > maxLines) out.pop()` ⇒ **整行丢弃、没有任何提示**。本批新增规则：

1. 折行后若行数 > `max_lines`：**保留前 `max_lines` 行**，并在**最后一行尾部**追加 `……`；
2. 追加前先从末行**逐字回退**，直到 `宽度(末行 + "……") ≤ maxW`（预算规则与既有 `uiThemeEllipsize` 一致）；
3. 若连 `……` 本身都放不下（`maxW - 宽度("……") ≤ 0`）⇒ 与 `uiThemeEllipsize` 同口径：**该行不画**（宁可少一行，也不许溢出）；
4. **纯渲染**，不参与布局（不改变行盒数量/位置，故既有排版判据不变）。

**三处实现必须同判据**：① 引擎 `krkr\game\ui_theme.tjs`；② HTML `复刻\replica.js`；③ **Python 实测port** `工具\gen_flow_layout.py::ui_theme_wrap`（供 M4 全量语料实测）。三者由 §六 的交叉闸门对同一张冻结期望表核对。
