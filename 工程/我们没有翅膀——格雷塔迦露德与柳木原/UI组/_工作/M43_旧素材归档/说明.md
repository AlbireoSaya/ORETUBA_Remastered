`chapter` 屏 15 个元素的 `asset` / `item_frame.asset` 引用**只有一件 PNG**：

| 素材 | 引用处 | 是否被他屏引用 | 处置 |
| --- | --- | --- | --- |
| `ui/panel_frame.png` | `chapter.panel_frame`、`chapter.list.item_frame`、`chapter.detail_frame` | **是** —— `10_dialog.json`（`dlg.choices.item_frame`）同时引用 | **不归档、不移动、不删除**（共享件；移动它会打断对话框屏） |

核查命令（**逐个引用点全库复核**，非抽样）：

```bash
grep -rn "panel_frame" layout/screens/ 复刻/ krkr/game/
#   → 10_dialog.json（保留）＋ 30_chapter.json（随屏删除）
grep -rn "chapter_card\|ui_ec5\|ec5_bg" layout/screens/ krkr/game/ 复刻/
#   → 无任何 layout / 代码引用（只在文档里被提及，见下）
ls krkr/assets/ui/ | grep -iE "^ec|ec5|card"
#   → 空：资产集内**根本不存在** ec5 / chapter_card 族
```

## 三、原版「章标题卡」族（`ec5_bg` / `chapter_card`）——**从未接入资产集**

`UI清单.md` 与 `工具/make_assets.py` 里登记过一个 A 类族 `chapter_card`（原名 `ec5_bg`，原版章标题卡）。
实测结论（本次复核）：

- `krkr/assets/ui/` 内**没有任何 `ec5*` 件**（445 件全量 `ls` 过滤为空）；
- `chapter` 屏的卡片实际走 **`ui/panel_frame.png` 九宫格 + 引擎绘字**（屏 note 已写明）；
- 故该族**没有可归档的磁盘文件**；它在 `工具/make_assets.py` 的取件清单条目已就地标注停用
  （`# ("chapter_card", ["ec5_bg"]), ← M43 已停用`），`UI清单.md` 两处族表行已标注删除。

## 四、色板（`layout/palette.json`）**未改**

按派单要求：**色板是共享资源，删键有风险**。本次**未删除任何色键**
（`chapter` 屏引用的 `@palette.letterbox / panel_fill / text_title / …` 均被其它屏或通用语义使用）。
`layout/palette.json` 的 md5 与改动前一致。
