## 4. B2 · 「对话框中的 6 个按键」到底是什么（用户问题的原文回答）

> **那 6 个三角不是按钮。** 它们是原版素材 **`ms_cursr.png`**——一张 **138×11 的精灵条，图上并排画着 6 个三角**（6 帧动画）。原引擎用它做「点击推进」的**闪烁指示动画**：每隔一段时间切换到其中一枚，形成「小三角在闪」的推进提示。`dlg.cursor` 的 `anim:{mode:"blink"}` 就是这个意思。
> M9 当初把**整条精灵**（w=207 = 138×1.5，随 1920 画布迁移放大）当作一个静态图贴了上去，于是 6 帧被**同时画出**，看起来就像「6 个并排的按键」。**它没有任何点击功能，从来不是 6 个按钮。**
> 按用户要求：**该元素已整块删除**（如实登记，不静默删掉了事；本条同步写入 `10_dialog.json` 屏根 `note`）。
> 注：`ms_cursr.png` 本身仍留在资产目录（未被删除、未被其它屏引用）。

## 7. ⚠ 过程中发现并修复的既有 bug（`uiDialogPartialLines` 字号错配）

**现象**：把全语料**最长 113 字**行注入运行副本后，实机只显示出 **77 字**，尾部 36 字**被静默截断**（`max_lines=4`）。

**根因**（`ui_dialog.tjs` 原第 188 行）：
```
var wrapped = uiThemeWrap(stage, fullText, w, ml);
```
`uiThemeWrap` 用 `layer.font` 度量宽度，而此处传入的是 **stage**，其 `font` 是**上一帧最后一个元素留下的字号**（对话框屏为 `dlg.hint` 的 **24**），**不是** `dlg.text` 的 42。于是：
- 这里按「24 px 字号」折行 → w=1224 下约 **51 字/行**，113 字 → 3 段；
- 渲染器 `uiThemeLayoutText` 会**先** `uiThemeApplyFont`（42 px）**再**折行 → 每段 51 字再折成 2 行 → 3 段 = **5 视觉行 > max_lines=4** → `uiThemeWrap` 尾部 `pop()` → **静默丢字**。

**修复**（`ui_dialog.tjs`，`uiDialogPartialLines` 内补一行，附详细注释）：
```
uiThemeApplyFont(stage, el.font, el);   // ★ M25：折行度量必须用本元素字号
var wrapped = uiThemeWrap(stage, fullText, w, ml);
```
`uiThemeApplyFont` 只写 `layer.font`，而渲染器对每个元素都会重设字体，**无副作用**。
