## 1. 加了哪 4 个字段

`m06_delivered_sample_ledger.py:55-72`（`APPEARANCE_FIELDS` 现 **25 个字段**，原 21 个）：

```python

    "kind", "x", "y", "w", "h", "asset", "z", "color", "opacity", "font", "align", "valign",
    "wrap", "max_lines", "sample", "nine", "state_assets", "action", "label",
    "visible_default", "line_spacing",
    "vis_flag", "vis_when", "layer", "dynamic",     # ★ E5 补入（4 个）
]
```

**为何是这 4 个**（都改变观感/行为，本就该进清单）：

| 字段 | 语义 | 本批相关性 |
| --- | --- | --- |
| `vis_flag` / `vis_when` | 显隐谓词（`fc_layer`/`fc_replay` 等） | 第 11 批 `fc.pbkick` 新增 `fc_replay`/`play`；第 12 批「两键互斥」机制依赖它 |
| `layer` | `_hit` 的层跳转目标（`action:"flow_layer"`） | 本批「`fc.entry.<NNNN>_hit` 的 `layer` 一字未改」**此前无闸门** |
| `dynamic` | 运行期填充层名（如 `flow_scene_frames`） | 右栏大播放窗画面层的契约字段 |

**顺手做的根治（单一来源）**：`m01` 原先**自带一份 `APPEARANCE_FIELDS` 副本**（有漂移风险，而 `m06` 文件头却写「与 `m01` 保持同一份清单」）。
现改为 `m01_screen1_appearance_diff.py:78-86` 从 `m06` 直接取用：
```python
return (m.DECLARED, m.DECLARED_NEW_IDS, m.DECLARED_REMOVED_IDS, m.DECLARED_LINKS,
        m.APPEARANCE_FIELDS)
LEDGER, LEDGER_NEW_IDS, LEDGER_REMOVED_IDS, LEDGER_LINKS, APPEARANCE_FIELDS = load_ledger()
```
