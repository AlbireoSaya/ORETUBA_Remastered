## 六、必须知道的 3 个例外（详见交付报告）

1. **`ld_over.png` / `sv_over.png` 是 RGBA 叠加层**（alpha 均值 33.4，77.7% 全透明，最大 alpha 153）。**丢 alpha 会得到近全黑画面**（正确混合后均值 (177,201,214) vs 丢 alpha (0,5,11)，L1 差 192/255）⇒ 这两件**必须保留 alpha**。脚本默认 `--alpha-mode keep-edge`：输出 RGBA，内容区 alpha 原样，新增左右条沿用边缘列 alpha。**该项需主代理确认**（派单原文写「RGB 不透明」，与大纲 §五 S6「原图本身带 alpha 的件除外」冲突）。
2. **`asu54.png` 源为 1610×1214**（非 1600×1200）：脚本按实际尺寸算几何，可正常跑；但它是唯一尺寸例外，验收时留意。
3. **几何不是「内容 1440 宽」**：画布宽取 8 的倍数（2136 而非 2133），故输出内容区 = **x∈[241,1679]、宽 1438**，横向缩放 0.898876 对纵向 0.900000，**存在 0.139% 横向压缩**（内容宽高比 1.33148 vs 4/3=1.33333）。肉眼不可见、且远在 V1 的 0.01 容差内，但**严格讲与 S7「保持像素宽高比」有 0.14% 偏差**；改口径须重跑全部，**本轮照既有实现不动**，是否接受请主代理裁决。
