## 三、需要你裁定的三个口径\r
\r
### 3.1 英文题字：保留 or 覆盖？（影响面最大）\r
`SAVE / LOAD / QUICK LOAD / BACKLOG / ALBUM / MOVIE / MUSIC` 与 `sys_menu` 的 `QUICK SAVE / SAVE / LOAD / CONFIG / TITLE MENU / EXIT` 均为**烘焙英文**（PSV 设计原本就用英文题）。\r
- **甲·保留英文**：零额外工作，PSV 观感原汁；我方原有中文屏题（如「系统设置」）改为英文或并存。\r
- **乙·引擎中文覆盖**：题字处需遮盖/除字后由引擎绘制中文（每屏多一道除字工序，但全中文一致）。\r
\r
### 3.2 中文烘焙件用不用（22 张确认弹窗为唯一有争议者）\r
- **甲·直接使用**：确认框文案固定为这 22 条中文（我方提示语已与其中多条语义一致，如「要覆盖存档数据吗？」）→ 最省、观感最好；代价＝文案写死，新增提示需重跑生图或退回空白板。\r
- **乙·全部走空白板＋引擎字**：任意文案皆可，但确认框视觉退回到「一块板＋引擎字」的朴素形态（PSV 的 YES/NO 图形与微光排版需自行复刻）。\r
\r
### 3.3 日文页脚（save/load/quick_load/bklog/gm_bg1/mu_bg/mv_bg 的 y988-1032 操作提示）\r
- **甲·引擎中文覆盖**（推荐）：页脚位置固定（y494-516 @1×，右缘 26），用引擎绘制「确定/删除数据/返回」等，与按钮动作一致。\r
- **乙·遮盖留白**：直接抹掉页脚，不放提示。\r
- **丙·保留日文**：不可接受（上屏留日文），不建议。\r

## 五、复核口径（本清单全部数字的来源）\r
\r
- alpha/文字定位：`getchannel('A').histogram()` 取 bin0/255；逐行/逐列 `crop((0,y,w,y+1)).getbbox()` 取左右极值；文字掩码＝「蓝饱和度 `b-r>45` 列聚类」或「`alpha>120` 且亮度<165 暗字聚类」或「亮度>238 白线峰值」。\r
- 差异比对（AI 件 vs 原件）：逐 4px 采样 `Σ|ΔRGBA|>60` 计差异像素，取差异 bbox。\r
- 去字件几何直接引自 `_工作\ISSUE-20260926-02_PSVconfig去字\复现脚本\rects_manifest.json`（入库）。\r
- 我方屏结构与会话口径引自 `layout\screens\*.json`、`layout\_schema.md`、`UI清单.md`、`会话交接_*.md`（最近一份）。\r
