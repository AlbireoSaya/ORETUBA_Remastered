## 五、坑与纪律（本会话新增，**都真踩过**）

1. **★ 判「装不装得下」必须以「像素上真正可见的底」为准**：元素矩形会骗你——横向（元素 296 → 可见面 283）与**竖向**（元素高 65 → 可见实体面仅 **48–49px**）两个方向都要量。本轮第一轮横向改对、竖向漏了同一件事，导致「四判据全绿却实机切头」被 vision 打回。
2. **★ 模型与引擎有 1px 系统性偏差**（引擎把文字块画得比几何中心高约 1px）⇒ 判据要按**引擎实测**定档，否则留下「产品差 1px 不达标」的假违规。
3. **★ 新数据字段必须确认两端消费点**（本轮 `line_spacing`：krkr `ui_theme.tjs::uiThemeElementSpacing` / HTML `replica.js::lineSpacing`），并用「改名 ⇒ 回落基线」的 A/B 自证。
4. **★ 轮廓/边缘类缺陷要「解析化」，不要按阈值打补丁**：底边凸起的根因是原件 alpha 在阈值附近抖动（x=167 处 229<230）造成 1px 掩码缺口 ⇒ 若靠调阈值修会让整条边外扩 1px。
5. **★ 量「边缘/柔光」必须以 50% 覆盖交叉点为界**（阈值 bbox 会把实体的 AA 过渡边算成柔光——本轮上一轮就是这么量错的）；**45° 对角量半径是有偏仪器**（TL 恒 −1.7 / BR 恒 +1.8），绝对半径用**相切拟合**。
6. **★ 「换用更高分辨率」在本工程不成立**：引擎按 `nine` 把左右端 **1:1** 摆、只横向拉伸中段 ⇒ 整张素材放大会把圆角**挤成椭圆**。只能「高分辨率作画 + 成品 1× 带 AA」。
7. **★ 不能只信「目视实机图」判断折角/端帽这类**：端帽半圆被节点美术盖住、实机不可见（vision 因此两次误判「圆角未生效」）；反过来**像素判据要用邻域/覆盖率**，盯单像素精确色会把圆角量成 0。
8. **TJS2 两条真知识**（已入 `引擎工作原理.md` §5.10）：`typeof` 数值返回 **`Integer`/`Real`**（写 `!= "number"` 会把**每条边**判非法且**不报错**）；**内联数组尾逗号会多出一个空元素**（源码 `tjs.y:774-776`）。
9. **`layerExDraw.dll` 集成四坑**：① 运行期落点是 `runtime\plugin\`，而 `run_*.bat` 的 xcopy **只在运行目录不存在时执行** ⇒ 新增 dll 必须补强制刷新；② 别塞 XP3；③ 仓库根有全局 `*.dll` ⇒ 入库件要放**有反忽略规则**的目录并双证；④ `if(...)` 块内 `echo` 带**裸右括号**会提前终止该块。
10. **★ 金标闸要求「真生成」才算验证**：`--dry-run` **不校验金标**。本会话因此漏了一次（-06 收尾改了生成器里 `SCREEN_NOTE` 的正文、只跑了 dry-run ⇒ 下一轮首次真跑被拒 EXIT=1）。**且 `--refresh-golden` 只改 `GOLDEN` 字面量**，**改不到** 生成器 `PRESET_TABLE` 与 `layout\_schema.md` 的金标表 ⇒ 重钉后必须**手改这两处**（两者曾因此与 GOLDEN 矛盾，一审打回）。
11. **★ 改 JSON 字符串内容一律「先生成候选串 → `json.loads` 通过 → 再落盘」**：本会话一次把**真实换行符**写进了 JSON 字符串、且修复只留在内存未落盘 ⇒ `23_save.json` 一度不可解析。**回滚前先想清楚会不会抹掉同分支的其它改动**（当时差一点 `git checkout`，那会连 x 位移一起抹掉）。
12. **Python 里拼 Windows 路径别用普通字符串**（`\U`/`\t`/`\r` 会被吃成转义或控制符——本会话踩了三次）⇒ 用 `chr(92)` 拼或 raw string。
13. **无参调用必须复现交付产物**：生成器＝「默认＝交付样例 + 金标闸（≠金标拒绝落盘）」，否则一次手滑就把交付件换成变体。
14. **闸门/自检会重写已入库的运行再生文件**（`t1_gate\*`、`mut_*_dump.html`）⇒ 合并前逐件判性质（幻影 CRLF／真内容同步／快照再生），并扫一遍暂存集里的 `.npy` 之类大中间量（本会话真扫出两件 16.6MB，已加 `*.npy` 忽略规则）。
15. **共享 `临时\ui_run` 会串证据**（多代理混入彼此的 run）；**一次只跑一个引擎**；`run_e2_fixture.py` 结尾的 `taskkill /F /IM tvpwin32.exe` **会误杀并发引擎**。
