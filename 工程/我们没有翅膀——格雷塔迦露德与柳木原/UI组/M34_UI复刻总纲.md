## 二、新标准（本组自定，不再沿用资源组口径）

| 项 | 值 | 说明 |
| --- | --- | --- |
| **设计画布** | **1920×1080** | 与《交汇协奏曲》一致；PSB 坐标 1:1 复用 |
| **窗口化** | `setInnerSize(1280,720)` + `setZoom(2,3)` | 与既有一致（用户已验） |
| **资产命名** | `x_ui_<屏>_<部件>[_<态>].png` | 新前缀 `x_ui_`，与旧 `x_gen_*` / 原版件**物理隔离** |
| **状态后缀** | `_off` / `_over` / `_on` | 对应 PSB 的 `オフ` / `オンマウス` / `オン` |
| **九宫格** | 面板类一律给 `nine`，按素材实测装饰区取值 | 禁止整图拉伸 |
| **文字** | **一律引擎绘制**，素材面**必须无字** | 《交汇协奏曲》把 `はい`/`Save`/`退出游戏`/角色名烘焙进图；**本作不复刻这一点**——这是唯一有意偏离 |
| **配色** | 冰蓝霜白（实测表见 `M34_风格锚点.md` §3） | 只换配色，结构 100% 照搬 |

> **「100% 复刻」的界定**：**几何与结构 100%**（每个部件的 x/y/w/h、层级、状态、组归属逐字照搬）；**配色与材质另起一套**（冰蓝霜白磨砂玻璃）；**文字一律不烘焙**（引擎绘制，这是本工程铁律）。

## 六、红线（沿用本工程既有铁律，不得突破）

1. **一切文字由引擎绘制**，素材面必须无字（生图 prompt 里强制声明）。
