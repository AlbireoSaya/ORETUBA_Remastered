## 四、坑表补充（**上一份 §三 坑表的增量**，两条都是这两轮踩出来的）

1. **改素材尺寸/增删素材后必须重跑 `工具\emit_asset_index.py`**：编辑器、`screen_index.js` 与尺寸判据都吃这份索引；漏跑会让编辑器报「无 nine 时 w/h 必须等于 PNG 实尺寸 X×Y」（M45d 实例）。
2. **编辑器校验与 `verify_ui.py` 是两套实现**，二者不一致时**以 `verify_ui.py` 为准**；再遇到「编辑器报硬错误但 verify_ui 过」，按序查：① 索引是否过期；② 校验是否漏了合法写法（例：`asset:null + dynamic:"<名>"` 的**动态层**曾被误报「缺 asset」，已在 `editor_ui.js` 加豁免）。
3. **`grep` 在 `UI组\` 下要加 `-a`**：4 个 `.bat` 是 GBK，普通 `grep` 会静默跳过（曾漏检巡演注释里的过期屏名）。
4. **不可见控制符**：用非 raw 字符串拼 Windows 路径时 `\a`/`\b`/`\2026` 会被 Python 当转义 ⇒ 反斜杠丢失、留下 U+0007/U+0008/U+0082（本轮修过多次）。**拼路径一律用 raw 字符串或 `chr(92)*2`，改完文档扫一遍 `Cc` 类字符。**
5. **删屏/删元素前先查素材是否被他屏共用**（共用则不归档）；归档一律「移入 `_工作\M<NN>_旧素材归档\` + 写说明」，**不删**。
6. **整体缩放按钮/控件必须同时改三件**：底板 image + 文字层（字号同比或按用户口径）+ 热区（随新底板外扩同样边距）。

5. **仍未实测**（沿用既有口径）：Win7 SP1 x64；**真人鼠标**观感（本轮全部证据 = 引擎离屏 PNG + 无头 Edge）；
   `>6 项`翻页时的逐项态（当前布局 3 项，翻页路径只做了「重建前清台账」的防御）。
