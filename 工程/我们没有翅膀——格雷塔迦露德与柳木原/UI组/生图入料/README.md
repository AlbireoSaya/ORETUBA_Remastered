## 投放规则

1. **文件名 = 任务书里的 ID**，例如 `A_系统屏底图\A1_save.jpg`、`B_功能图标\B01_save.png`。
2. 同一 ID 出多张备选：加后缀 `A1_save_02.jpg`；**默认取不带后缀的那张**，要换备选请告诉我。
3. 每批填好本目录下的 **`_生成记录.tsv`**（模型 / seed / 步数 / CFG / 完整提示词）。**生图不可复现，没有参数记录就没法回溯**。
4. 出图尺寸不用管（1024×1024、1344×768 都行），**不要自己放大**；裁切与缩小由我按 D1 规则做。
5. 一次一批，**批内风格统一**（最好同一 seed 家族 + 同一套提示词模板）。
6. 🆕 **（2026-09-20 教训，务必遵守）导出必须是「真 alpha（PNG-32）」**。**不要用「透明背景预览」截图**当透明图——
   那会把**棋盘格烘焙进像素**：原画的半透明白与棋盘白在像素层混合，信息**永久丢失**，事后去背不可行（本批已因此报废 2 张，见下）。
   自检：`python -c "from PIL import Image;print(Image.open('x.png').mode)"` 须输出 **`RGBA`**，输出 `RGB` 即无 alpha、必重导；
   或肉眼：透明处应随背景变化（软件提示），而非固定不变的灰白棋盘图案。
