## 2. 投放规则（**请务必遵守**）

1. **生成参数请记进各批次 `_生成记录.tsv`**（`..\A_系统屏底图\_生成记录.tsv` 等同构；模板见 `生图补图任务书.md` §9）：
   `批次 / ID / 文件 / 模型与版本 / seed / 步数 / CFG / 完整提示词 / 备注`。
   **生图不可复现，没有参数记录就没法回溯、没法重做、没法做风格延续。**
2. **导出必须真 alpha（PNG-32）**——凡是需要透明的（图标、底纹、装饰）：
   - **不要用「透明背景预览」截图**，那会把**棋盘格烘焙进像素**（原画半透明白与棋盘白在像素层混合，信息永久丢失，事后不可恢复；本工程已因此报废 2 张）。
   - 自检：`python -c "from PIL import Image;print(Image.open('x.png').mode)"` 须输出 **`RGBA`**，输出 `RGB` 即无 alpha、必重导。
   - 肉眼：透明处**随背景变化**（软件提示）＝真透明；**固定不变的灰白棋盘图案**＝假透明（已烘焙）。
3. **不要自己放大**出图（D1 裁决）；裁切与缩小合规。出图尺寸不限（1024×1024 / 1344×768 都行），我会规范化到目标尺寸。
4. **一次一批、批内同 seed 家族**；跨批混模型/seed 会立刻出戏。
5. **画面内不得有文字与人物**（唯一例外：⑤ 的角色卡允许画角色）。
6. 文件命名严格用任务书 ID（如 `A1_save.png`、`B11_page_prev.png`、`C01.png`）。
