### T1.2 评估：这能否让构建多接一类演出事件？——**能接一类（Fade）；其余「缺参数/已有来源」，不接**

把 27 项已采纳按「构建是否已有来源」分三类（依据：`资源组\演出\演出_ot.tsv` 的 `op` 只有
`chr_expr 13310 / se 3652 / other 2484 / bg 1414 / chr_add 902`；背景层已换吃 PSV `SpriteBG` 金标；BGM 有挂接表+切换点）：

| **Fade 类** | **`0x19F9C FadeOut`（ot）`0x172BC`（otp）** | **此前完全无来源**（`stage[]` 无 fade 事件） | **接**（§T2） |
| 效果/转场类（缺口） | `0x1B888 Flash`、`0x1B69C EffectQuake`、`0x7480 Window`、`0x1B040 InOut_Act`、`0x186C8 sp_move`、`0x10150 bg_move`、`0xFDF4 bg_zoom`、`0x13300 bg_blur`、`0x2A150 cross` | **无来源**，但**参数未解出** | **不接（缺什么见下）** |

**「缺口类」为什么不能接（逐条写明缺什么，可复跑）**：读 `解出_ot.tsv` 的对应行，
这些 V 的 `arg1/arg2/arg3` 与 `time_ms` **全为空**：

```
== 0x1B888 (Flash) ==     seq=5  arg1= arg2= tm=   ｜ seq=328 arg1= arg2= tm=
== 0x1B69C (EffectQuake) == seq=5 arg1= arg2= tm=
== 0x7480  (Window) ==    seq=5  arg1= arg2= tm=
== 0x1B040 (InOut_Act) == seq=26 arg1= arg2= tm=
```

⇒ **缺的是「参数位解析」与「渲染侧实现」**：解码器目前只对 `TIME_FAMILY` 已登记的族解出 `ms`
（Flash 的强度/颜色、Window 的框、cross/bg_zoom 的目标都不在其中）；且 `ui_staging.tjs` 也没有
这些 op 的消费分支。**故不接——没有参数的事件是空事件，接了等于假数据。**
（对照：Fade 之所以能接，正因为它的**唯一参数 `ms` 已解出**且被 PSV 金标证实。）

> ⚠️ 一处**已知冲突未在本批处理**（沿用 `定名_说明.md` §6.8 登记）：`0x10428` 的 PSV 金标名是
> **`SpriteMove`**，而既有 `TIME_FAMILY["ot"][0x10428]` 的族名是 **`bg_anime`**。本批**不动**，
> 冲突保留在案（标签表 `name` 取 `V_NAMING` 的金标名 `SpriteMove`）。

## §T2 Fade 载体接进构建

### T2.1 机制（PC 侧独立，不用金标）

```
资源组\演出\Lucifen命令族标签.tsv   ← carrier 列非空的 V 即 Fade 载体（ot 0x19F9C / otp 0x172BC）
        ↓ 逐节点读
编程组\SOB0解码\解出_<源>.tsv      ← arg3 == "V=0x…" 的行；time_ms 即该节点时长（ms）
        ↓
build_stage(): ev += {op:"fade", seq, dur:ms, dir:"out"}   → sort(seq) → out[]
        ↓
scene_*.tjs: stage:[ %[ seq:3, op:"fade", slot:-1, fam:"", t:"", x:0,y:0,w:0,h:0,z:0, dur:800, dir:"out" ] ]
```

**方向 `dir` 恒 `"out"` 的依据**（不是猜的，`_fade_audit.py` 真跑）：同一批载体节点，
`round(ms×0.06)` 落在**同 seq PSV `FadeOut.time`** 集合里的比率 vs 落在 **`FadeIn.time`** 里的比率：

| 源 | 帧∈FadeOut.time | 帧∈FadeIn.time | 结论 |
| --- | --- | --- | --- |
| ot | **315 / 410 = 0.768** | **0 / 405 = 0.000** | 载体节点**就是 FadeOut**（带时长的那一半） |
| otp | **13 / 16 = 0.812** | 3 / 16 = 0.188 | 同上 |

PSV 侧 `FadeIn` 主金标恒 `time=0`（瞬时复位，564/577 行）⇒ **PC 没有 FadeIn 独立节点，本批不伪造**。
（`FadeOut` 583 行里 451 行 `time>0`，才是「有时长的淡出」。）
