## §1 T1 · 读 `V` 处的 func_lib 结构（窗口式，口径与敏感度）

### 1.1 读到的是什么

`func_lib.sob` 是 **SOB2**（`ss=175052`、`se=177978`、`header_end=102120`；六表条数 `[1343, 805, 0, 0, 10612, 0]`）。`V` 是**该文件缓冲内偏移**（`V_max=0x2A4B4 < ss`），4 字节对齐 93/93。

从 `V` 起按 BASE 元数表走项流（`[tag][payload…]`，见 `decode_sob0.BASE`），**走到第一个「引用字」为止**（引用字是 6 表键，不可能是 tag）。**全部 93 个 V 共 5 种形态**（数字可复跑：探针 `--json` 的 `t1[*].head` / `walk_tags`）：

| 形态 | head | 前缀（项流头几项；`|` 分隔项、`…` 表示仍在走） | V 数 | 其中命名命令 V | 说明 |
| --- | --- | --- | ---: | ---: | --- |
| **A** | `0x0B` | `0B <k> \| 20 <symref> <cref> \| 1E 0 <cref> \| 0C <k> \| 01 \| …` | 51 | 43 | 主流；`<k>` 在 `0B` 与 `0C` 两处重复 |
| **B** | `0x20` | `20 <symref> <cref> \| 1E 0 <cref> \| 01 \| …` | 30 | 28 | A 形去掉 `0B <k>` 前缀 |

## §2 T2 · 与 PSV 金标逐条对拍（**多口径，分开报**）

### 2.1 口径定义（写死，避免混报）

- **分母**：`N` = 该源**语料场 ∩ PSV 金标场**（ot **362**）。
- **场级**：V 场 = 该 V 出现过的场；T 场 = 该 PSV type 至少出现一次的场；`precision = |V场∩T场|/|V场|`，`recall = |V场∩T场|/|T场|`，`base = |T场|/N`，**反例 = V场 \ T场**（附清单）。
- **seq 级**：seq 键 = `(scene_id, seq)`。V 的 seq 集 = 该 V 各节点经 `decode_sob0.SeqMap` 映射到的 seq；T 的 seq 集 = 该 type 的非 `Message` 行所在 seq。
- **唯一 event 标签（本批主判据）**：seq 集里**恰有 1 条非 Message PSV 行**的子集 ⇒ 该 row 的 type 即标签。
  - `D_strict` = 追加「该 seq 上 PC 命令节点恰 1 个（即本 V）」⇒ **归属唯一，最强金标**；
  - `D_all` = 不加节点数约束（`avg_nodes` = 每个标签 seq 的平均 PC 命令节点数，>2.5 表示归属不唯一）。
- **计数签名**：逐场 `n_V(sid)` vs `n_T(sid)`：`ex` = 逐场精确相等率；`sad = Σ|n_V−n_T|`；`rel = sad / max(Σn_V, Σn_T)`；**反例 = 有 V 无 T 的场**。
- **位置签名**：节点 seq 在该场 PSV 事件序中的归一化位置（0=场首，1=场尾）。
- **参数级**：命令实参里的字符串 == 同 seq PSV 行的 `name`（角色名/件名）。

### 2.2 阈值（**自定并写明；达不到一律「未定」**）

| 规则 | 内容 | 阈值 |
| --- | --- | --- |
| **R1** | 唯一 event 标签 ⇒ 采纳 | `purity_strict ≥ 0.90 ∧ D_strict ≥ 20 ∧ **基准率护栏 q(type) < 0.90**` |
| **R1f** | 唯一 event 标签按**族**（top1+top2） | `D_strict ≥ 20 ∧ (top1+top2)/D ≥ 0.95` |
| **R2** | 参数级（实参串 = PSV name） | `样本 ≥ 100 ∧ 一致率 ≥ 0.90` |
| **R3** | func_lib 内嵌串（窗口敏感度） | `W∈{0x120,0x200,0x400} 首串相同且非空 ∧ 命令节点 ≥ 5` |
| **R3b** | 实参串 = 语料 `title_variants` | `逐场一致率 ≥ 0.90` |
| **R4** | 计数签名 | `ex ≥ 0.60 ∧ rel ≤ 0.35 ∧ type 场覆盖 < 0.95`，且**只看 sad 最小的 3 个候选** |

> **R1 的基准率护栏 `q(type)`（一审 RV-NAME 提示⑦）**：`q(type) = 该 type 在「单事件 seq（恰 1 条非 Message 行）」中的占比`。若某 type 本身占掉大半单事件 seq，则「唯一 event 标签」也近乎无条件成立 ⇒ 需护栏。
> **实测（可复跑，探针 `--json` 的 `r1_prior`）**：单事件 seq = **13,811**；先验 top5 = CharacterOpen **9,560 (0.6922)**、SePlay 800 (0.0579)、SeStop 674 (0.0488)、CharacterActionEnd 655 (0.0474)、SpriteBG 449 (0.0325)；**`q_max = 0.6922 < 0.90` ⇒ 本批 R1/R1f 的 14 个采纳项均不触发护栏**（数值已登记进 `decode_sob0.py` 的 `V_NAMING` 注释）。

> ⚠️ **R4 阈值 `rel ≤ 0.35` 属「批次标定」，不是有理论依据的阈值（一审 RV-NAME 附加提示）**：
> 把 93 个 V 的「最佳计数签名 `rel`」排序，实测空档为 **[0.3188, 0.4314]**；**0.35 恰是能纳入 `0x1B040`(rel=0.3188) 的最小两位小数**。换言之，它由**本批数据的经验空档**标定，而非先验推导 —— 后续若要改动口径（换语料、换源），**该阈值必须重新标定**。
