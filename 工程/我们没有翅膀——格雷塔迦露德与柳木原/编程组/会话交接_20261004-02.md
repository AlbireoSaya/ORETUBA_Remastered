## 六 本会话新增的坑（接 `会话交接_20261004-01.md` §六 坑 52 之后）

53. ★ **TJS2 字典字面量的键只能裸标识符**：`%{ "k": v }` 是**语法错误** ⇒ **整份 `.tjs` 装载失败**
    （症状像挂载顺序问题：下游全是「未找到 Member"‹该模块的函数›"」）。要字符串键得**先建空字典再 `d["k"]=v`**。
    唯一线索行＝`[UI] execStorage FAIL : <文件> : 语法有误`。同族：**数组字面量不能有尾逗号**、`;` 不能当元素分隔。
    另：**Dictionary 没有 `.count`**（打出来是 void）。**纪律：手写/生成 `.tjs` 后必须真装载并看那行 OK/FAIL。**
54. ★ **`new Layer(win, null)` 抛内部错误**（`DrawDevice.cpp:141`）——`ui_flowfull.tjs:14-15` 早记过，本轮又踩。
    要挂**已建好的宿主层**（`UIStoryWin.primLayer`，退 `stageLayer`/`UIAssetHost`）。
55. ★ **EVR 画面在我方图层之上**，且**抓不到**：`exportPng`/GDI 抓屏/`PrintWindow(PW_RENDERFULLCONTENT)` 全失败
    （实测全白）⇒ **影片类改动只能肉眼验收，不得声称「已截图验证」**。
56. ★ **判据选错会把"不存在"当成事实**：我按 `next_kind == end` 得出「A/B 页没有终局」并上报，
    用户质疑后才查出**真正的判据是「终章（エピローグ）场景」**（源侧 ED 就挂在那儿）。
    **教训：报"某某不存在"之前，先问「我用什么字段找的？有没有更贴近语义的字段？」**
    （`title_cn` 里的「终章/尾声」就是更强的证据）。
57. ★ **进程内 `redraw()` 脏检查 + 转场在场 return** ⇒ 同一相位连画两次会让**下一相位的截图停在上一状态**；
    **自检状态机还要注意「在哪一相位关掉计时器」**——我把关闭写在中间相位，后加的相位永不执行（本轮踩到）。
58. ★ **`git worktree remove --force` 可能只删一部分**并把该 worktree 从注册表注销（再删报 `not a working tree`）；
    **删前必须对该目录做逐文件 md5 去重比对**（基准 `git ls-tree -r main`）——本会话正是靠它抢救出 2 个非重复文件。
    另：**Windows 上 Python 的 `print` 写 `\r\n`**，bash `read -r` 回读的路径带尾回车 ⇒ 用硬编码清单或 `tr -d '\r'`。
    ⚠️ 另记：**又踩一次 Bash `/tmp`（在 C 盘＝工作区外）**，临时清单一律写 `临时\`。
