## 一 翻转公式与值域（含自证）

**实现**（`build_story.py`，`STAGE_Z=10` 之后）：

```python
PRIORITY_MAX = 10

def layer_z_from_pri(pri):
    if pri is None:
        return STAGE_Z
    s = str(pri).strip()
    if s == "":
        return STAGE_Z
    return STAGE_Z + (PRIORITY_MAX - int(s))
```

- **单调递减**：`pri` 1→2→…→10 给出 z 19→18→…→10，**数值大者更靠前**，方向与源义一致。满足派单要求 ①。
- **值域**：`pri∈[1,10] ⇒ z∈[10,19]` ⊂ 闸门 `[E]` 接受域 `[STAGE_Z, STAGE_Z+PRIORITY_MAX]=[10,20]`。满足要求 ②。
- **缺省语义**：`None`/`"" ⇒ STAGE_Z(=10)`，未知量报告已证「`cpri` 为空的行两极性恒等」；本实现**不让它们产生任何差异**。满足要求 ③。
- **唯一换算点**：otv 与 gold（`g_z`/`g_add`）两路都调 `layer_z_from_pri`，全库再无第二处 PSV→z 换算（闸门 `[D]` 白名单已只认该形态）。

**值域实测自证**（`证据_self零影响与极性.md`）：`ot_s04_08a` 翻转前 zset=`[12..19]`、翻转后 `[11..18]`（同一组 `pri` 各自减 1 后镜像，逐一对应）。

**两条新判据（均在 `audit_layer_source.py`）**：

- **`[D4]` 源码方向**：`check_polarity_source()`——要求 `PRIORITY_MAX = 10` 存在、唯一换算函数 `layer_z_from_pri` 存在，且其**函数体内**出现单调递减式 `PRIORITY_MAX - int(...)`；出现递增式 `STAGE_Z + int(...)` 即 FAIL。
