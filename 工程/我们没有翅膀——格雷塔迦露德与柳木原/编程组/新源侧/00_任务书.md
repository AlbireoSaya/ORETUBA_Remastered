## 一 目的与验收标准

**目的**：把六源**源侧**的逐行演出数据（位置 / 时长 / 移动 / 退场 / 层序 / 效果转场参数）从原始文件里**真正解出来**，做成一份比 `资源组\演出\演出_*.tsv` 更完整、可被 `build_story.py` 消费的「新源侧」真值层。

**验收标准（可失败）**
1. 每个模块给出**原始字节级证据**（`文件:op:偏移` + hex 片段），不能只有汇总数字。
2. 与 PSV 金标（`编程组\PSV演出\立绘事件流.tsv`，**422 场**——金标覆盖场数口径：ot_ 329 ＋ otr_ 53 ＋ otp_ 12 ＋ otv_ 28；**`ota`/`np` 无 PSV 覆盖**）**逐 `(scene_id, seq, op)` 对拍**，门槛按 op 分级（不可一刀切 1.000）。
3. 「参数未解」的行**必须带 `param_ok=0`**，且**构建器侧独立复算同一判据**——防止「空事件」被当演出消费。
4. 端到端：`build_story.py --staging-source self` 输出与现状**逐字节可比**（或差异逐条列明）。
