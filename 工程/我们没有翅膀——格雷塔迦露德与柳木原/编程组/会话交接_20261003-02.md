## 六 本会话新增的坑（**接到 `会话交接_20261003.md` §六 之后，编号续接**）

29. ★ **插件「静默不画」，而"调用成功 + 计时非零 + 计数递增"完全不能证明画出来了**。
    `drawLines`/`drawPolygon`（`layerExDraw`）对**点集形状错**与**颜色 α=0**一律**不报错、不抛异常、照常返时**，
    只是**一个像素都不画**。我把「耗时非零」当成「已绘制」，据此宣布「层预算实测达成」——**结论是错的**，
    是一审挡下来的。**判据必须是像素级**（或至少「按上游 `manual.tjs` 的嵌套点集 ＋ 0xAARRGGBB 传参」）。
30. **点集要嵌套**：`drawLines(app, [[x,y],[x,y],…])`，**扁平 `[x1,y1,x2,y2,…]` 不画**。
31. **pen/brush 要 `new GdiPlus.Appearance()` ＋ `addPen`/`addBrush`**，传普通字典报 `Invalid instance type`；颜色 **0xAARRGGBB**。
    而 **`Layer.drawText` 的颜色要 `0xRRGGBB`**（传 `0xAARRGGBB` 完全不画）——**同一个"颜色"在不同 API 上位宽约定不一致，必须逐个查**。
