## 三 · 目标数据格式（**本文档的核心交付物：消费契约**）

### 3.1 交付物

**按源各一张 TSV**：`演出_ot.tsv` / `演出_ota.tsv` / `演出_otp.tsv` / `演出_otr.tsv` / `演出_otv.tsv` / `演出_np.tsv`（源代号 ∈ {`ot`,`ota`,`otp`,`otr`,`otv`,`np`}）。

- 落点：`资源组\演出\演出_<源代号>.tsv`（**本工程尚无 `演出\` 目录，需新建**；若资源组更愿放既有 `资源组\交接编程组\` 下亦可，但**须在文档与台账登记实际落点**，见 §六）。
- 编码 **UTF-8（无 BOM）**；分隔符 **TAB**；**不加 CSV 引号**；只有首行表头，无注释行。

### 3.2 列定义（**9 列，顺序固定**）

| 列 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `scene_id` | string | 否 | 场景 id，**必须等于** `scene_<源>.jsonl` 里已存在的 `scene_id`（如 `ot_s01_01a`） |
| `seq` | int | 否 | **唯一连接键**：本 op 在**该行显示之前**生效的行号（1-based，取自 `lines[].seq`）；**场景开场（首行之前）记 `seq=1`**；**`seq=0` 仅用于 `skip` 行** |
| `op` | enum | 否 | 演出动作，**闭集**（见 §3.3） |
| `target` | string | 是 | 目标素材统一名（`<源代号>_<原名>`，如 `ot_asu07a`）／立绘族代号／角色代号；无对象时留空 |
| `arg1` | string | 是 | 第一参数（语义随 `op`，见 §3.3） |
| `arg2` | string | 是 | 第二参数 |
| `arg3` | string | 是 | 第三参数 |
| `evidence` | string | 否 | **该行从哪里解出**：脚本名 + 偏移 / 字符串表序号 / 命令码 / Task 编号（**写"哪个脚本 + 哪个位置"，不要写行号**——本工程实测注释行号引用 6/6 全飘） |
| `confidence` | enum | 否 | `exact` / `inferred` / `unknown`（见 §3.4） |

### 3.3 `op` 闭集与 `arg1..arg3` 语义（**枚举，不得自造值**）

| `op` | 含义 | `target` | `arg1` | `arg2` | `arg3` |
| --- | --- | --- | --- | --- | --- |
| `chr_add` | 立绘出现 | 立绘统一名 / 族代号 | 位置锚（`left`/`center`/`right` 或 `x,y`） | 层序 | — |
| `chr_remove` | 立绘退场 | 立绘统一名 / 族代号 | — | — | — |
| `chr_move` | 立绘移动 | 立绘统一名 / 族代号 | 目标位置 / 方向 | 时长（ms 或 `unknown`） | — |
| `chr_expr` | 立绘表情/差分切换 | 立绘统一名 | 差分后缀（`a`–`n`） | — | — |
| `bg` | 换背景/CG | 背景统一名 | 转场方式（`cut`/`fade`/`rule:<编号>`） | 时长（ms 或 `unknown`） | — |
| `se` | 音效 | 音效统一名 | 播放方式（`once`/`loop`/`stop`） | 音量或 `unknown` | — |
| `bgm` | 背景乐 | BGM 统一名 | 动作（`play`/`stop`/`fadeout`） | 淡入淡出时长（ms 或 `unknown`） | — |
| `movie` | 影片 | 影片统一名 | 播放次数/是否全屏 | — | — |
| `wait` | 停顿 | — | 时长（ms） | 依据（`voice_duration`/`fixed`/`unknown`） | — |

| `other` | 已解出但不属上述闭集 | — | 原始命令助记符 | 原文参数 | — |
| `skip` | **该场景无逐行演出数据** | — | 原因（如「脚本无 PIC/SE/CHR 路径引用」「opcode 未逆向」） | — | — |

### 3.4 `confidence` 取值定义

| 值 | 判定 |
| --- | --- |
| `exact` | 源侧**直证**：如字符串池引用序、`op.sob` 96 步型、`otv` 的 `[TaskN]` 线性序、`np` 的 `.bs5` 常量池首次引用序 |
| `inferred` | 由**相邻登记 / 形态不变量**推定（如 `op.sob` 的 `bg_move` 与背景引用按形态配对） |
| `unknown` | 有对象但**无从判定**（如时长、坐标不可见） |

### 3.5 与 `lines[].seq` 对齐的做法（**必须照此**）

1. **`seq` 是 1-based**，与 `scene_<源>.jsonl` 的 `lines[].seq` **同一坐标系**（`schema.md` §2.1 明示"场景内 1-based 序号（本模块自生成）"）。
2. **`empty_slot` 行仍占 `seq`**：空槽（`jp`/`cn` 均空）**不跳过**，其 `seq` 照样计数（实测 `ota_11_3b0` 第 82 行为空槽，`seq` 连续 1..82）。若某 op 锚定在空槽上，就填该空槽的 `seq`。
3. **锚定语义 = "在该行显示之前生效"**：同一 `seq` 可有多行（多个 op 在该行前依次触发），按文件**物理先后**为触发序。
4. **场景开场（首行之前）的 op 记 `seq=1`**，并在 `evidence` 注明"在首行之前"。
5. **`skip` 行：`seq=0`**，`target`/`arg2`/`arg3` 留空，`arg1` 写原因，`confidence=unknown`。**允许该场景只有这一行**。

### 3.7 纪律（**违反即视为不合格交付**）

- **一条 op 一行**，不得把多个动作塞进同一行、塞进备注列或塞进 `arg` 串。
- **没有逐行数据就留空表 + 每场景一行 `skip`**；**严禁编造、严禁"按常识补全"、严禁用 `cast` 反推立绘时序**——`cast` 是"谁在场"，**不等于**"第几行谁出现"（`11_演出挂接说明.md` §四 明示二者互不包含）。
- 同一场景内 `seq` **不必连续**（只在有 op 的行出现），但**不得越出该场景 `lines[].seq` 的取值范围**（除 `skip` 行的 0）。
- `target` 一律用**素材库统一名**（`<源代号>_<原名>`），与 `资源总账.json` / 各源 `_清单.json` 的 `out_relpath` 口径一致；**不得按 basename 跨源解析**（`交接说明.md` C3/C4）。

### 4.2 ⚠️ P0 `ot` 的关键前提（**必须先做小规模探针，再投工时**）

**`ot` 的脚本本体不以 `CHR\` 路径引用立绘**（`10_全流程资源支撑审计.md` §三.2 引 `本篇_产出报告.md` ：「CHR 不产出」「BGM / CHR 本篇不按名引用」；`01_剧情流程图.md` §7.2 S1 亦记「**无 `CHR\`、无 `BGM\` 路径引用**」）。这意味着：

- `ot` 的**背景/CG 与音效可以照 `op.sob` 之法从字符串池引用序恢复**（因为它们确实是路径串）；
- 但 `ot` 的**立绘不能照搬字符串池法**——立绘是按**差分名令牌**被演出命令调用的，令牌可能：① 作为裸串在字符串池里；② 作为 opcode 的**数值操作数**（归档索引）；③ 落在 `voice` 字段（旁证：`ota` 有 **87 行**把差分名 `CIN###`/`CIT###`/`LR2##` 误当语音，说明**差分名令牌在语料里确实存在**）。
- **判定方法（请资源组先交出这份一页结论，再决定是否全量做）**：抽取 `ot` 若干代表脚本的字符串池，检索形如 `^[A-Z]{2,3}\d{2}[a-n]?$` 的裸串（立绘差分名），并与 `资源组\krst素材库\ot\chr\` 的 989 个实际文件名做**存在性准入**；命中率若显著 >0 ⇒ 走字符串池法；若 ≈0 ⇒ 立绘逐行**必须先逆向 opcode 数值操作数**，属 `R1` 的硬骨头，**工时须单独估**。

> **对 P0 的务实拆分**：`ot` 的 **背景/CG + 音效逐行**（高可行）**先交**；**立绘逐行**（待探针）**后交**——不要因为立绘难而把整个 `ot` 卡住。
