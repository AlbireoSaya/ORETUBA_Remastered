## 五、正文内嵌显示控制码与符号回退（**硬性**）

**控制码**：正文可出现 `<10>\`、`<-6>\`、`<8>`、`<20>` 等**引擎内嵌控制码**（字号/音量级，正数＝喊叫、负数＝轻声）。
**译文必须把该控制码原样、原位置、原写形保留**（如 `<-6>\“羽田君”`），**不得翻译、不得删除、不得改动数字**。

**符号（作品级裁决，硬性）**

| 原符号 | 处理 | 说明 |
| --- | --- | --- |
| `♪`(U+266A) | **`☆`** | **不可 GBK 编码**；**不得删除**（删除＝丢信息） |
| `≪` `≫` | `《` `》` | 不可 GBK 编码 |
| `・` | `·` | 不可 GBK 编码 |
| `─`(U+2500) `―`(U+2015) | `——` | 破折号统一 |
| `〜`(U+301C) | `～` | 个数 1:1 |
| `゛`(U+309B) | `～` | 不可 GBK 编码，按语气落 `～` |
| `　`(U+3000) | **删除** | 全角空格 |
| `(^_^)` 等颜文字 | 按原文保留 | 半角可见字符，可编码，属原文内容 |

**感叹词拖音（あー／ふーん／うーん／おー）**：一律 `～`；`——` 只留给**句尾拖长**与**破折号/中断**。

**促音独用**：`「っ！」` / `「……っ」` / `「…………っ！」` → **「唔」**（保留原省略号个数与末尾标点）。
