## 二、文本承载与编码

| 项目 | 值 |
| --- | --- |
| 脚本格式 | **SOB0**（本作**剧情与系统脚本一律 SOB0**，无 TOB0；74 条目中 69 个 `.sob`） |
| 结构 | `SOB0` + `u32 table_size` + 若干张地址映射表（每张 `u32 条数` + 条数×(`u32 key`,`u32 value`)）+ `u32 strings_start` + `u32 strings_end` + 字节码 |
| 文本定位 | **第 5 张映射表（下标 4）是字符串指针表**；字节码中 `(cmd & 0xFFF00000) ∈ {0x01800000, 0x01700000}` 的指令引用文本 |
| 字符串形态 | **台词**：`#<说话人标签>\<语音ID>$&<正文>$`；**旁白/章节标题/系统提示**：无 `$&` 的裸串；**资源串**（`PIC\x.ELG`、`SE\x.OGG`）纯 ASCII，不译 |
| 源编码 | **Shift-JIS（CP932）** |
| 目标编码 | **GBK** |
| **长度约束** | **无等长约束**——字符串由指针表寻址，译文可任意变长（与 R 版 TOB0 的硬约束**完全不同，不得套用 R 版等长化流程**） |
| 内嵌控制码 | 正文可出现 `<10>\`、`<-6>\` 等字号/音量控制码，**必须原样原位置保留** |

## 六、⚠️ 授权边界（用户 2026-09-17 指令，最高优先级）

**新米汉化资源只允许取其「人名 / 地名」，其剧情译文一律不得使用。**

- ✅ 允许：人名 / 地名 / 组织名 / 特定名词的中文写法。
- ❌ 禁止：把任何汉化组（含新米、含 R 版本项目）的**成句剧情文本**搬进译文。
- ✅ 剧情正文**由本工程从头翻译**（自 `语料\原文\` 的日文原文起译）。
- 交付与审查时，若某句译文与他方汉化高度雷同，须能自证为独立翻译。
