## 三、文体与标点（要点；细则见通用层）

- 语体优先级：**原意 > 人物语气与视角 > 自然中文 > 原作风味 > 原句形式**；
  禁止网络烂梗，禁止翻译腔（弱动词+抽象名词、滥用"被/的/地"、无意义"们"、连接词泛滥）。
- 角色语气按作品层 `术语表.md` §三（主角三人：鷹志温和内向 / 鷲介油滑话密 / 隼人粗暴简短）。
- 敬称按作品层 §四：`○○さん`（同学 / 同辈）→**○○同学**；社会人语境→**○○小姐 / ○○先生**；
  `○○先輩`→○○前辈；`くん`（姓氏+）→○○同学、（名字+）→○○君。
- 标点**只用 GB2312 范围内的 GBK 全角**：`，。！？`、`……`（两个）、`——`、`～`（U+FF5E）、`、`、`；`、`：`、`（）`；
  - `「」`→`“”`，`『』`→`‘’`；`〜`→`～`（个数 1:1）；`！？` 保持原序与个数；
  - **删除全角空格 `　`（U+3000）**；不得用半角标点、不得用 SJIS 码位标点。
- 原文 `\n`（换行）**保底保留**在译文对应位置（槽内换行不得增删）。

## 四、字段说明（输入 JSON）

```json
{"i": 123, "file": "11_1a.tob", "idx": 5, "kind": "line", "spk": "鷹志", "jp": "　こんにちは、誰かさん。"}
```

- `i`：全局序号（**输出必须原样带回**）；`file` / `idx`：脚本名与条内序号（供你判断上下文）；
- `kind`：`line`＝正文台词/旁白；`title`＝章节标题（**照译**，同样一条一条来）；
- `spk`：**原文说话人标签，仅供你判断是谁在说话**——**不要翻译、不要写入译文**，也不要删改；
- `jp`：日文原文。行首的 `　`（全角空格）是排版缩进，译文**不保留**（按通用规范删除）。

## 五、输出格式（**严格照此，否则无法合并**）

写入 `翻译工作区\批次<NN>_译文.json`，UTF-8，结构：

```json
{
 "batch": 1,
 "tr": [
  {"i": 0, "cn": "…"},
  {"i": 1, "cn": "…"}
 ]
}
```

- `tr` 的**条数与顺序**必须与输入 `lines` 完全一致（同一批内按 `i` 升序）；
- `cn` 不得为空、不得残留日文原文、不得含 `\n` 以外的控制字符；
- 译文必须**可 GBK 编码**：`・≪≫♪〜―` 等不可编码字符按 `lucifen-unpack §五` 回退表处理
  （`・→·`、`≪→《`、`≫→》`、`♪→☆`、`〜→～`、`―→—`），**不得因此跳过整条**。
