## 三、本批符号 / 拖音处理执行说明（无需入表）

- `≪≫` → `《》`（s03_11a#3、#27、#47、#229；s03_11b#16、#51）；`『』` → `‘’`（s03_10d#92、#345、#354、#375、#427；s03_11b#545、#753）；`「」` → `“”`。
- `　`（U+3000）全数删除；`〜`/`♪`/`・`/`─`/`―` 本批 0 处。
- 拖音：**感叹词（あー／えー／はー／やー／んー／まー／おー／あらー／うはー／へー）一律 `～`**；**句尾拖长（ですよー／くださーい／ですかー／ありますー／ましたー 等）与破折号、中断一律 `——`**；`ー` 个数按 1:1 落 `～` 或 `——`。
- 内嵌显示控制码 `<N>\`：本批 0 处；`\n` 换行：本批 0 处（已核）。
- 假名残留 1 处（s03_11b#753「是‘さん’啊」）属作品层 §三之三十七 的**正当例外**（被讨论的日语语言现象：鸣 用 `さん` vs 亜衣 用 `くん` 的对比）。
