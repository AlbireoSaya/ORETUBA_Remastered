## 四、⚠️ 汉化补丁层（`UI_汉化补丁层\`）——仅供对照，不作交付使用

游戏目录下的 `SYS\`（**mtime 2026-03-07，与 `ORE_TUBA_CHS.dll` 汉化补丁同日**）铺了 **151 个松散 `.elg`**，

**判定正本依据（三重）**：① 文件 mtime（归档＝出厂日期，松散＝补丁日期）；② ELG 头类型（`\x01` 压缩＝原版打包，`\x20` 未压缩＝事后重制）；③ 画面目视。

本次**交付以原版归档为准**；汉化补丁层单独输出到 `UI_汉化补丁层\` **仅为对照**（看清哪些 UI 图被本地化过），
其演绎内容属第三方汉化组资产，**不得直接作为自用素材**（与「新米汉化只可取人名/地名」的授权边界同源）。

## 五、复现命令

```bash
cd "E:/ZCode Workspace/Galgame/工程/我们没有翅膀"
# 全量：SYS.LPK 的 1099 个 .elg → PNG
python -X utf8 工具/ui_to_png.py
# 只转某一类（正则）
python -X utf8 工具/ui_to_png.py --only "^gl_|^tl_galry"
# 另转汉化补丁松散层（对照用）
python -X utf8 工具/ui_to_png.py --loose "D:/Gal/[Navel]我们没有翅膀/SYS"
```

  逐条容错（单条失败只记录不中断）；输出 `manifest.json`。
- 依赖：Pillow —— 本机用工作区内 vendored 版本（`工具\pylibs`），脚本已自动加入 `sys.path`。
