# ORETUBA_Remastered

本仓库持续进行《我们没有翅膀》的 KiriKiriZ/TJS2 忠实复刻与研究。内容包括 OT/OTA/OTR（Lucifen）与 OTV（MAGES TaskDSL+CRI）相关源码、工具源码、研究文档、对白原文及既有译文。

为公开源码与研究资料库，不含图像、音频、视频、可执行文件、归档、凭据与工具二进制，故不能作为独立可玩游戏运行。当前已审查 RVM 支持 36/47 条操作码，不代表完整游戏进度。

目录含六个相关工程目录、工程记录与技能文档；精确源基线及哈希清单见 `publication-manifest.json`。初始快照的本地历史未发布，未收入本地未提交改动。
