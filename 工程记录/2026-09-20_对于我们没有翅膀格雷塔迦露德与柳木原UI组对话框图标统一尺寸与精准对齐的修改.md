## 根因（**主代理像素实测坐实**）

**源图 `功能图标.png` 是 3×3 网格，但每个图标在各自格子内的位置并不一致**：
- 源 351×234 单元格内，**内容中心 x 极差 72 px、y 极差 23 px**（实测：x 208.0/170.5/138.0/203.0/168.5/140.0/203.5/169.0/135.5，y 126.0/126.5/128.5/116.5/117.0/117.0/106.0/106.5/105.5）。
- M22 按**均匀网格**切分 → M26 又**整格缩放**（351×234 → 80×53）→ 偏移被原样带进每张图；再「居中摆进格子」时，**图居中 ≠ 内容居中** ⇒ 9 格内容位置参差。
- 实测 M26 产物（80×53）的**内容中心 x 极差 17 px、y 极差 5 px** —— 与用户截图所见一致。

## 改动清单

### 1. `工具\make_dialog_icons.py` —— 改为「按内容裁切 → 统一等高 → 居中」
| 项 | 旧（M26） | **新（M27）** |
| --- | --- | --- |
| 做法 | 整格 351×234 直接缩到 80×53 | **按 alpha 包围盒裁出内容 → 统一缩放到内容高 64 px → 居中放进与格子同尺寸的画布** |
| 输出尺寸 | 80×53（内容位置随源图漂移） | **80×75（＝格子尺寸；内容居中）** |
| 内容一致性 | x 极差 17 px / y 极差 5 px | **x/y 极差 ≤0.5 px** |

- 输出仍为 `x_gen_dicon_01..09_<语义>.png`（**9 件，同尺寸 80×75**）。
- 顺带把内容从 40 px 放大到 **64 px** ⇒ **标签可读性一并改善**（用户上一轮提过「提高清晰度」）。
- 幂等：连跑两次 9 件 md5 相同。

### 2. `layout/screens/10_dialog.json`
- 9 个 `image` 的 `w/h` = **80×75**（= PNG 实尺寸，**无 `nine`** ⇒ 运行期 1:1 零缩放）；`x` = 格 x − 0.17（让 80 宽的图正好覆盖 79.67 的格子）、`y` = 格 y。
- **元素 id 同步为新顺序**（此前 id 仍沿用 M23 的旧顺序语义，如 `icon_03_skip` 却挂 config 图 —— 功能无误但会误导；现改为 `icon_03_config`，`hit` 同步）。
- 顺序保持用户指定：`Q.SAVE / Q.LOAD / CONFIG / SKIP / PREV / CLOSE / SAVE / LOAD / REPEAT`。
