## 任务目的

用户 2026-09-24 报告：在布局编辑器里观察「配置」屏时，通过 flag 把 `cfg_page` 切到系统页 / 声音页后，
**另一页的元素仍然显示**，怀疑这批元素「没打 flag（空）」；并给出一份人工核对名单（17 件系统页值元素 + 角色列表 4 类）。

**本任务目标 = 确认这些元素为什么在两个配置页面都可见**（诊断，不擅自改）。验收标准 = 每条结论都有

## 结论与依据

### 结论（一句话）

**名单上的元素都带 flag，只是把 `vis_flag`/`vis_when` 用在了「值 / 选中态」上，而不是「页归属」上。**
页归属由**同一行的 `hit`** 承担（`config_set_*` / `config_char_*` 热区全部 `vis_flag:"cfg_page"`），
值元素的跨页显隐靠**运行期派生**兜住；而用户看到的是**编辑器「按 flag 预览」这条 raw flag 路径**——
它只做逐元素 flag 比对、**不跑派生**，于是呈现的是「未派生」的中间态。
**产品侧（引擎实机 / HTML 复刻）均无跨页残留，已实测。**

### 依据 1 · 数据侧：名单元素的 flag 归属（`layout\screens\25_config.json`，435 件）

- **435 件里只有 20 件完全没有 `vis_flag`**，逐件核对后全部属**跨页共用的外框 / 页签 / 三键 / 预留行**：
  `cfg.dim`、`cfg.frame`、`cfg.page_strip`、`cfg.tab1_hit`/`cfg.tab2_hit`(+各自 `_bg`/`_tx`)、
  `cfg.reset_hit`/`_bg`/`_tx`、`cfg.btn_game_*`/`cfg.btn_title_*`/`cfg.btn_end_*`，
  以及 3 件 `visible_default:false` 的预留行 `cfg.row_cfmovie_*`。⇒ **这是刻意的，不是漏打**
  （屏顶 note ③「页签条两页共用，故页签图/字/热区不带页 flag」、note ⑥.6「预留行三件刻意不带任何 flag」）。
- **名单上的元素都带 flag**（抽样原文）：
  · `cfg.o_display_on` → `"vis_flag": "cfg_v_display", "vis_when": "window"`
  · `cfg.o_voicecut_on_tx` → `"vis_flag": "cfg_v_voicecut", "vis_when": "off"`
  · `cfg.ch_asu_tx_sel` / `cfg.ch_asu_pill` / `cfg.pv_name_asu` / `cfg.pv_face_miy` → `"vis_flag": "cfg_vchar", "vis_when": "<族名>"`
- **页归属写在 hit 上、且可机检**：本屏 66 个 `config_set_*` / `config_char_*` 热区**全部**
  `vis_flag:"cfg_page"` + `vis_when:"sys"|"snd"`；按机制侧同一算法复算得 **17 条值键→页映射**
  （10 sys：display/facewindow/drama/effect/voicecut/curhide/savedialog/loaddialog/allskip/textcolchg；
  6 snd：mute_vol_master/bgm/se/sysse/voice/char；+ `cfg_vchar`→snd），**无遗漏、无错页**。
- **为什么不能把页 flag 也发给这些元素**：判定语义里 `vis_flag` **一个元素只允许一对**
  （`layout\_schema.md` §四；`krkr\game\ui_screens.tjs::uiScreenElementVisible` 有判据指纹守门），
  而 **hit 必须带页 flag**（否则非本页的热区会在另一页吃掉点击 —— §四铁律一）。
  ⇒ 数据侧只能「hit 带页、值元素带值」，值元素的页归属**只能是算出来的**。
