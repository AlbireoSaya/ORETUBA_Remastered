## 风险、警示与未完成项

### 本次踩到 / 确认的坑

1. **`flowchart.pimg` 的文件名不可用于反查**：`manifest.jsonl` 的 `name` 字段是 `chr(0x5000 + index - 1)` 的占位符（11,012/11,012 全部符合），**零信息量**。真正的名字来自 Hxv4 表的 `filename_hash`（`Blake2s-256(UTF-16LE(名) + UTF-16LE("xp3hnp"))`）。且 `startup.tjs` 一例存在「XP3 索引名 ≠ Hxv4 逻辑名」的错位——**做存在性判定用「哈希集合成员」比「逐行定位」更稳**。
2. **PSB v3 的资源表本身没有名字**：`chunk_offsets/lengths` 是匿名的；「键名 ↔ 图像」的映射在**对象树**里（`root["<layer_id>.tlg"]["$res"]`），部件路径由 `layers[]` 的 `layer_id` 沿 `group_layer_id` 链拼出。用字符串池顺序给资源命名是**错的**（字符串池是键字典）。
3. **TLG5.0 的 magic 第 11 字节是 `0x1a` 而非标准 `0x00`**（`54 4C 47 35 2E 30 00 72 61 77 1A`），字段布局一致；按标准 0x00 判会漏。
4. **`工程\交汇协奏曲\UI复刻\渲染证据_画面A/B*.png` 实为 ZCode 窗口截图**（1936×1048），不是流程图渲染证据——该复刻 HTML 的渲染证据**并未真实产出**。已如实登记，未修正（不属本次范围）。
5. **`_工作\M27_*` 编号已被占用**（另一会话在 01:19–01:21 留下了 `krkr_dialog.png` / `synth_icons.png` 等）→ 本次证据改用 **M28** 编号。
6. **磁盘上 3 个文件与 main 仅行尾（CRLF/LF）差异**（`_工作\M26_measure_title.py`、`会话交接_20260920_UI组.md`、`工具\make_dialog_icons.py`）——**内容一致，非他人在途改动**，本次**未提交**它们，避免把 CRLF 引入仓库。
