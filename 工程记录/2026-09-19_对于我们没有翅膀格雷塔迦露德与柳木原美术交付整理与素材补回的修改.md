## 风险、警示与未完成项

### 风险与回滚

- **回滚方式**：全部改动提交在 issue 分支；回滚即 `git revert`。三个 `w12_*.py` 均**幂等且带 `--check`**，可安全重跑。
- **PNG 不受 git 保护**：`美术统一\` 与 `美术统一_超分\` 的 PNG 被 `.gitignore` 忽略（设计如此，可再由 `unify_*.py` / `upscale_by_bbox.py` 再生），故**文件层面的改名/移动/新增不进版本库**，其状态由三张清单记录。这是既有设计，但意味着**清单是唯一的状态凭据**。
- **硬链接前提**：`素材超分\in`/`orig` 依赖 NTFS 同卷硬链接才「删了不释放空间」；若日后库被移到其它卷，该结论不再成立。

### 警示（新增，建议并入交接文档）

1. **「md5 不同」不等于「素材不同」，但「宽高比不同」也不等于「素材不同」**——本工程两头都踩过：前者造成重复处理（96.3% 仅尾部 ≤16 字节差异），后者造成**误并丢失素材**。**唯一可靠的判据是目视同高对照**：本次三种自动度量（多尺度对齐残差、边缘图 NCC、局部块差异）**全部无法区分**同画不同画幅与不同内容（实测同画残差 29.2 vs 不同画 30.8）。
2. **门控只是筛选，终裁必须目视**——这是第二次被证实：门控误报率 83%（前一轮 30 组拆错 25 组），本轮「不拆」方向又有 5/160 错判并造成实际丢失。
3. **跨目录同名是静默杀手**：381 件同名不同图，按 basename 查会**取错而不报错**。
4. **子代理中间产物落点**必须核对（前一轮 W11g 落在工程根，本轮已迁正）。
5. **提交信息含反引号必须走 `git commit -F <文件>`**——反引号会被 shell 当命令替换，导致消息残缺（前一轮实际发生并已 amend 修正）。
