### 素材是怎么做的（**逐条给依据**）

**背景 `x_title_bg_1280.png`**
- **中央 = `资源组\美术统一\系统UI\tl2_bg1.png`（800×600）逐字节 1:1**，摆在 D1 规定的 `(240,60)`（4:3 源 1:1 居中）。
- **四周 = 同一张素材重度模糊（GaussianBlur 72）+ 压暗 62% + 提饱和**得到的**氛围延展层**（UI 组新建素材）。它不是「把素材放大后当画面」——细节不可辨认，只提供同源色调。
- 中央区外一圈**柔和内阴影**（渐变，非描边线）+ 轻暗角，使 1:1 画面与氛围层之间不出现硬切边。
- ⚠️ **中途弃用的一版**：曾试「镜像延展」（取相邻 240 px 翻转，1:1 像素、完全不放大），但该素材左右边缘有人物，镜像后出现**明显的人物重复**（左边缘多一个黑发少女、右边缘多两个）→ 弃用。两版预览见 `_工作\M9_证据\`。

**logo `x_title_logo.png`**
- **装饰 = 原版 `tl1_logo.png` 的 `y>=118` 区域**：该带**行最暗像素亮度 ≥185，即完全无文字**，是纯羽毛（证据：逐行亮度剖面，见 `_工作\M9_证据\logo_diag.png`）。**1:1 原像素、不缩放**。
- **文字 = 「我们没有翅膀」**：楷体（`C:\Windows\Fonts\simkai.ttf`，72 px），原版 logo 的深蓝 `#1A5CA8` + 白色外沿（八向描边），与原版「深蓝字 + 浅色外沿」同构。
- **副题 = "under the innocent sky"**：DejaVu Sans Mono Oblique 17 px，浅色 + 深色描边（背景是暗场，深蓝字读不清，故改浅色）。
- ⚠️ **未采用原版日文与雪花**：原版 logo 的日文「俺たちに翼はない」位于 `y<118`，**与雪花交错**——按亮度阈值抠除会残留字形的浅色描边（试过 172 与 215 两档，见 `logo_diag.png`），无法干净分离。故只用其无字羽毛带，**如实登记为取舍**。

**菜单**
- 7 项，顺序按用户指定：`START / LOAD / CONTINUE / FLOWCHART / GALLERY / CONFIG / EXIT`（依次对应 开始游戏 / 读档 / 继续(快速读档) / 流程图 / 鉴赏模式 / 设置 / 退出）。
- 字体 `font.faces = ["DejaVu Sans Mono", "DejaVu Sans Mono Bold", "DejaVu Sans"]` + `bold: true`，34 px，白色 + 深蓝投影（3 px）。
- **不设按钮底板**（原版标题屏菜单就是纯文字），与参考图一致。
- ⚠️ **`DejaVu Sans Mono` 不含 CJK 字形**——这是菜单用**英文**的原因，也与原版（START/LOAD/…）一致。若要中文标签，须改用中文字体（见「未完成项」）。
