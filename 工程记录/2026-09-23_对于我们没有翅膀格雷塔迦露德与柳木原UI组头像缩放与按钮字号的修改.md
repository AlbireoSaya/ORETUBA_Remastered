**几何口径（为什么这样缩放）**：批量集的构图不变量是「**头宽 ≈ 画框宽的 103%**」（以头宽归一）。用户说的「1.5× / 1.15×」指**裁剪区到成品的缩放系数** ⇒ 保持裁剪区与构图不变、把成品整体缩到 1.15/1.5 = 0.767 倍：**360×450 → 276×345**。这样①构图不变（仍是「只到肩膀下方一点点」）、②所有角色的头像依旧观感一致（头都占框宽 ~103%）、③底边仍在 y1015。

## 风险、警示与未完成项

1. **头像右沿缩到 x276 后，与文字左沿 x380 的间隙变成 104px**（原 20px）。用户本轮只要求「缩小头像」，**未动文字位置**；若要把文字收近，改 `dlg.name`/`dlg.text` 的 `x` 即可（两端同改）——已在元素 note 里写明。
2. **「1.5× / 1.15×」是用户对我方术语的引用**：本工程的口径是「裁剪区 → 成品」的缩放系数；因批量集以头宽归一，**每个角色的实际放大倍率仍随其头宽而变**（M44 一审已量化：相对 1× 源 1.37–3.33×）。本轮只是把**整体系数**从 1.5 调到 1.15。
3. **未实测**：Win7 SP1 x64；真人鼠标观感。
4. 回滚：把 `m44_make_faces.py` 的 `BOX_W/BOX_H` 改回 360/450 重跑 + `dlg.face` 的 `w/h/y` 改回 360/450/565 + 六个 `_tx` 的字号改回 36。
