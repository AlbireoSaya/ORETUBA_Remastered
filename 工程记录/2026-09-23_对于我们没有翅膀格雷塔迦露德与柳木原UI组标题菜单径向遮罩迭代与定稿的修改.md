## 风险、警示与未完成项

1. **浓核覆盖与不规则度是此消彼长**：径向模型下，若要"极其不规则"（P1，扰动 ±28%），菜单两端浓度会掉到 17/255；定稿选 P3（扰动 ±18%）兼顾。**要改这个均衡只需改生成器里的 `amp / C0 / FADE` 三个数并重跑**。
2. **强度与形状是两个独立旋钮**：强度 = 元素 `opacity`（越大约浓；本值 26 = 10.2%）；形状 = 换素材（四档在证据目录，`--install` 一键装回）。
3. **径向/边缘淡出类素材必须检查"淡出是否在画布内归零"**（C 档左缘 α=82 的暗边即此坑；本轮定稿档左/右缘 α=0 ✓）——已入交接坑表。
3b. **上缘残留是结构性的**（一审复核）：椭圆竖直半轴 580 > 素材上边距 568 ⇒ 素材顶行落在淡出区内（α max 69）。已量化证明**不可见**（在 logo 足迹内、按真实 logo alpha 合成后 max 0.63/255），故未处理；仍要归零就把素材上边界再上移或下移椭圆中心。
4. **上方扩散钳位**：三轮时用户要求"上方再收 50px"而当前仅 30px，收完为负（即 0）；0 会让遮罩上沿变成硬边，故**钳到 6px**并显式报备（如需硬边可明示）。
5. **本轮的验证纪律教训（我自己的）**：一次临时 shell 断言写成"两串相等"却在两侧都取到空值时**假通过**（打印了 ✓）——随后改为**绝对路径 + 文件非空断言**才拿到真结论。**凡"相等"类断言，必须先断言取值非空。**
5b. **度量也要审**（一审 R5）：我原先用「12 向等值半径极差」证明形状不规则，而该度量把 y 乘了 1.6、与椭圆半轴比不匹配 ⇒ **理想椭圆也有 110px**，这个「证明」其实是噪声。**凡用一个指标下结论，先算该指标的"零假设基线"**（这里是 amp=0），基线不为 0 就不能用。
6. **未实测**：Win7 SP1 x64；真人鼠标观感（本轮证据全为引擎离屏导出 + 程序合成）。★ **观感已由用户本人验收**：六轮每一轮都先看引擎导出实机图再给口径，终值（不透明度 10%）即用户裁定。
6b. **⚠️ 顺带发现：三份历史 `工程记录\` 里有不可见控制符**（与 M42 无关，同一根因：**用非 raw 字符串拼 Windows 路径**时 `\2026` / `\0` / `\a` 被 Python 当成转义 ⇒ 反斜杠丢失、留下 U+0082 / U+0001 / U+0007 控制符，肉眼看着像少了反斜杠）：`2026-09-17_对于我们没有翅膀AfterStory剧情汉化的修改.md`（1 处）、`2026-09-17_对于我们没有翅膀PSV美咲线资源提取的修改.md`（1 处）、`2026-09-17_对于涅布＊普拉斯素材提取的修改.md`（2 处）。**按 §一 铁律 4「历史记录只增不改」未动这三份**，仅登记上报请用户裁决。本轮**自己触及的**文件已修：交接 3 处、`UI组\to-do-list.md` 1 处、`Galgame.md` 1 处（并清掉交接里 130 处重复 CR）。
