## 任务目的

用户三项指令（验收标准逐条对应）：

1. **「彻底删除『主页 章节选择 chapter』页面，现在只能从流程图中选择剧情。」** ⇒ 数据 / 两端代码 / HTML 复刻 / 索引 / 巡演清单 / 文档**不留任何悬空引用**；剧情入口改由**流程图**承担。
2. **「关于对话框，请你居左对齐人名和文本，然后在左边添加人物头像图(如图)，把握好这个位置，我会在编辑器中人工微调。」** ⇒ `dlg.name` 与 `dlg.text` 共用同一左沿；左侧新增说话人立绘层，位置按参照（《月影魅像》对话框左下）把握、留待用户在编辑器微调。
3. **「现在对话框页面的 dlg.content 是干什么的？可以给我加一层全白背景(放到画布最底层)吗？这样能方便我观察。」** ⇒ 先答（见下），再加观察用白底。

**`dlg.content` 是什么（第 3 问的答复）**：它是对话框屏的**剧情背景层**（`kind:image` + `dynamic:"story_background"` + `content_box:"@auto"` + `asset:null`）。运行时由编程组/演示层按当前场景的**源代号**从根 `content_boxes` 取框位填图：`ot`/`otr`/`ota`/`otp` → (360,90,1200,900)、`otv` → (240,132,1440,816)、`np` → 满幅 (0,0,1920,1080)；数据里写的是 ot 的默认框位。因它是 `asset:null` 的动态层，编辑器与巡演里**什么都不画**，看到的黑来自它下面的 `dlg.letterbox`（z=0 满幅黑矩形）。
