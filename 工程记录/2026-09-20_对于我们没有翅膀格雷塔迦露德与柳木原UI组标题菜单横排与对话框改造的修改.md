### 3. **主代理修复的两个真缺陷**

**① `uiDialogPartialLines` 折行用错字号（M25 发现并修）**
折行时用的是 `stage.font`（上一元素残留的 **24**）而非 `dlg.text` 的 **42** → 折行位置与渲染器不一致、行数翻倍超 `max_lines` → **113 字长台词被静默截断到 77 字**。修复＝补一行 `uiThemeApplyFont(stage, el.font, el)`。

**② HTML 复刻：`hit` 的三态贴图没设 `background-size`（主代理发现并修）**
- **现象**：krkr 实机标题屏 7 个按钮排布正确，**HTML 复刻却全部重叠**（对比图 `_工作\M25_证据\row_compare.png`）。
- **定位过程**：① 先量布局数据（7 件 290×81、内容间距 28 px、**数据正确**）；② 用 1:1 渲染 + 模板匹配定位画布，逐像素量文字块起点（krkr 首块 x=225 / HTML x=257 → HTML 落在「自然尺寸」位置）；③ 做最小隔离测试证明 `.ui-image-img{width:100%}` **工作正常**；④ 最终定位到 `buildHit()`：它用 `background-image` 画 `state_assets`，**但没写 `background-size`** → 浏览器按**图片自然尺寸（439×122）**绘制，盖在正确缩放的 `image` 元素上造成重叠。krkr 侧 `uiWidgetDrawHit` 按 `el.w/el.h` 画，故那边正常。
- **修复**：`buildHit` 的三态贴图补 `backgroundSize='100% 100%'` + `backgroundRepeat='no-repeat'`（与 `list.item_frame` 分支既有的写法对齐）。
- **验证**：修复后 HTML 与 krkr 的按钮行**逐块位置一致**（`row_compare_fixed.png`）。

### 4. 回答用户的提问：「这 6 个按键到底是干什么用的？」
> 那 6 个三角**不是按钮**，是原版素材 `ms_cursr.png`——**138×11 的精灵条，图上并排画着 6 个三角**（6 帧动画）。原引擎用它做「点击推进」的**闪烁指示**（逐帧切换其中一枚）。M9 当初把**整条精灵**当静态图贴上，于是 6 帧被同时画出，看着像 6 个按键。**它没有任何点击功能。** 已按要求整块删除，并如实写入 `10_dialog.json` 的屏根 note。
