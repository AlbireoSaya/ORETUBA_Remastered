## 风险、警示与未完成项

### ⚠️ 正本判定：汉化补丁的松散层与原版归档**不是同一批图**

游戏目录下 `SYS\`（mtime **2026-03-07**，与 `ORE_TUBA_CHS.dll` 同日）铺了 151 个松散 `.elg`，
**含文字的 UI 图已被换成中文**（实测：`gl_chr1` / `gl_scene` / `mc_galry` / `tl1_logo`）。
判定正本用**三重证据**：① 文件 mtime（归档＝2008 出厂，松散＝2026 补丁）；② ELG 头类型（`\x01` 压缩＝原版打包，`\x20` 未压缩＝事后重制）；③ 画面目视。

→ **交付以原版归档为准**；汉化补丁层单独输出到 `UI_汉化补丁层\` **仅供对照**（看清哪些 UI 图被本地化），
其演绎内容属第三方汉化组资产，**不得直接作为自用素材**（与「新米汉化只可取人名/地名」的授权边界同源）。
