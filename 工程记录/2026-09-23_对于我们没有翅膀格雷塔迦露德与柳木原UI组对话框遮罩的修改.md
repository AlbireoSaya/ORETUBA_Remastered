## 任务目的

用户在 M38「对话框完全无框」之后追加要求：
> 「对话框我还是想和《月影魅像》那样**加一层黑色渐变透明遮罩**，这样对于文本显示效果更好。」

**交付**：一张程序生成的竖向渐变遮罩素材 + 一个遮罩元素，使正文与角色名在亮画面上更可读，**且不新增引擎能力**（只用现成的 `image` + `opacity`）。
验收标准 = 遮罩范围**实测盖住文字**（不是按数据框估）、过渡无接缝、文字对比度提升、画面未被压毁、两端一致、全部闸门绿。

**参数由用户在量化对照图里亲自选定**（过程见下「改动清单·五轮选档」）：**贴底 350px、线性剖面 `α=255·t^1.0`、底部不透明度 90%（`opacity` 230）**。

## 风险、警示与未完成项

1. **「90%」是参数口径、不是可见强度**：因为最底 90px 落在黑边条（letterbox）内，**可见画面里最大只有 α≈0.66**；换算出"画面层（y90..990）被覆盖约 28.9%"。**不要按"90% 一定很浓"去想象它。**
2. **强度与范围是两个独立旋钮**：改强度只动 `dlg.mask_bottom.opacity`（**不必重出素材**，素材上限 255）；改范围/曲线才需出配套高度的新素材（命名 `…_<高>.png`，旧件归档不删）。
3. **未加的守门（如需请明说）**：目前没有任何自动检查保证"遮罩上沿必须 ≤ 最低文字元素顶沿"——本轮的结论靠 `_工作` 里的实测脚本（`?hide=` 藏元素再作差）。若要把它变成数据级判据，属新增判据（本轮未加）。
4. **未实测**：Win7 SP1 x64；真人鼠标/真机显示器观感（本轮证据全为引擎离屏 PNG + 无头 Edge）。
5. **证据目录约 92 MB**（`_工作\ISSUE-20260923-01_M39_证据\`，含 25 张原始帧 + 12 张引擎导出）：**属可再生产物**，建议入库只保留 `定稿3_*`/`定稿2_*`/最终实拍与量化文本，原始帧按需重跑再生。
6. **回滚**：删 `krkr/assets/ui/x_ui_dlgmask_bottom_350.png` + 从 `10_dialog.json` 删 `dlg.mask_bottom` 那一个对象 → 重跑 `gen_layout.py` 即回到 M38 状态（生成物随 `git checkout` 复原；旧 400 版与旧屏数据均在归档目录）。
