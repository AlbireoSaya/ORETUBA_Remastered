## ⚠️ 两个实测坑（本次最重要的产出）

### 坑 1：`background:"transparent"` 这个 API 参数**单独给不生效**

4 组对照 × 各 2 次，**100% 复现**：

| prompt 措辞 | 返回 |
| --- | --- |
| `transparent around it`（描述式） | **RGB**——棋盘格烘焙进像素，信息不可恢复 |
| `Transparent background with a real alpha channel.`（指令式，前置） | **RGBA** ✓ |

**结论：真 alpha 靠的是 prompt 明确要求，不是 API 参数。** 这也解释了为何首次批量 3 件全部拿到 RGB。
风格锚点里的透明指令已改为**前置**。

### 坑 2：模型**不遵守 prompt 里指定的左右顺序**

| 条目 | prompt 里写的顺序 | 实际生成的顺序 |
| --- | --- | --- |
| FC-3-1 | 上上下下下（up 在前） | **▼▼▼▲▲▲（down 在前）** |
| FC-3-8 | play / stop / close / close | **✕ ✕ ▶ ■** |
| FC-4-1 | heart / note / cross / star / check | **✓ ✕ ♥ ♪ ★** |

**处理**：33 件拆件全部**按目视实际内容重新命名**，不沿用 prompt 顺序。
**教训：多元素 sheet 的件名必须由目视指派。**
