## 风险、警示与未完成项

1. **⚠️ 静默缺陷已确认（本轮新发现，未修）**：`verify_ui.py` 的 [1] 引用完整性**完全不覆盖 `state_assets`**
   ——120 条三态图引用不在检查范围，**缺件会静默通过**。本次 28 件三态图恰好吃这条链路，
   故补法清单里把「修 `iter_asset_refs`」列为必做项；**在修好之前，「三态齐备」没有自动验收依据**。
2. **⚠️ 标题屏现有 `pressed` 键是死数据**：7 个 hit 的 `pressed` 都指向旧圆形图标的 `_on` 图，
   而 krkr 侧根本不读 `pressed` ⇒ 用户摆好文字后需把这 7 个键改指向
   `x_ui_btntxt2c_<key>_press.png`（等编辑器加了三态槽后可点选）。
3. **两态素材的语义重叠待划清**：`replica.js:1514-1517` 的 `.ui-hit-pressed`（110ms 瞬闪）
   与 `state_assets.pressed`（按住期间的状态图）是**两套机制**，改代码时必须明确区分，否则会出现双重反馈。
4. **未派独立 reviewer / 未派子代理**：本轮为素材派生（脚本 + 逐件目视）与只读取证；
   **独立一审仍缺位**——连续多轮登记为流程缺口。
5. **本分支仍未合并 main**；主工作树 `UI组\` 是 git 视野外的镜像副本（详见 -01 记录第 8 条），
   本轮已把 28 件新素材 + 重生成索引 + `_工作\M35_*` 同步过去，两侧自洽（434 件 / 索引 434）。
6. **回滚方式**：删除 `x_ui_btntxt*_{on,press}.png` 共 28 件即可回到 -01 状态（406 件）；
   随后重跑 `emit_asset_index.py`。三态图可由 `btn_states.py` 从常态完整再生（确定性，无随机）。
