## 结论与依据

1. **错位根因＝合成方式，不是提示词**：该 API 对 `/v1/images/edits` 的输入**整幅重绘并重排**（构图、比例都可能变）。
   上一版把**原图 1:1 贴回**中央 ⇒ 「AI 画的屋顶/砖墙」与「贴回的原图」在缝处错层、出现重影与重复结构。
   ★ **测量漏洞（我的）**：上一版只验了「贴回后的内容区」（恒为 maxdiff 0），**没有验「模型有没有动内容区」**，
   因此没能在交付前发现 2048×1152 返回图中内容已被重排。
2. **掩码方案实测不可行**：按 OpenAI 口径随请求提交 `mask`（中央 alpha=255 保护、两侧 alpha=0 待补），
   返回图中央区与输入内容比对 **PSNR 13.25 dB / maxdiff 255** ⇒ **掩码被完全忽略**。
   ⇒ 该 API **无法做「保住原画、只补两边」的受控扩图**。
3. **「整幅 AI」两版成品（用户建议路线）**：

| --- | --- | --- | --- |

| 掩码提示词 | `_样张\API全幅\掩码\A\bg82e.jpg` | `_样张\API全幅\掩码\混合\bg82e.jpg` | `0e2b0c286ab45c6e` |

   对比图：`工具\lyai-image-api\out_bg82e_edge\对比4_整幅AI.png`（①原图 4:3 ②本地 LaMa 拼贴 ③整幅AI-v2 ④整幅AI-掩码）。
   观感：**无错位、无重影、细节成形**；代价＝画面被 **AI 全幅重绘**（人物/建筑细节与原作有差异、构图可能重排），
   与任务书 §二.2「原内容 1:1 不重采样」**冲突** ⇒ 采用前须用户裁决并通知编程组变更契约。
