## 验证方式与结果

### 1. 抽取与译文规模

- 候选：`scan_sysui_v2.py` 扫 24 个系统文件，第二遍共新增 **136 段**；
  **逐段目视分诊**后认定显示文本 **42 条**补入，其余 **94 段**判为**数值表误判**
  （`04 00 <2B> 00 00` 递增偏移、`81 9b 01…` 序列化记录等）。
- 写回后再做残留扫描，另得 **23 处单字符**（`gallery.sob` 11 / `config2.sob` 11 / `title.sob` 1），
  与任何已写行**均无重叠**、同样判为数值表；**二审抽检后同意该判定**
  （reviewer 的家族级口径为 96 处，差异只是统计范围不同——本记录只统计「与已写行无重叠」的段）。
- 工作单 **289 行**（= 第一版 247 + 加宽 2 条 ｢｣ 串 + 新增 42 条）；
  **写回 286 条 + 豁免 3 条**（字体名 `ＭＳ ゴシック`）。
- 等长化结果：`equal 77 / padded 209 / truncated 0 / keep 3 / none 0`。
- 校验器：`工具\verify_sysui.py`（可复跑：逐条比对 + 残留扫描 + 打印 md5）。

## 风险、警示与未完成项

1. **只做了字节级 + 启动级验证**：设置画面 / 存读档对话框 / 报错框**未逐屏目视确认**。
   原因＝本机有程序长期占据前台（`SetForegroundWindow` 被前台锁拒绝、`AttachThreadInput` 亦无效），
   抓不到游戏焦点画面；而**菜单说明气泡只在游戏持有焦点时显示**。
   ⇒ 请用户实机点几下（CONFIG / LOAD 各页签、退出确认框），异常就截图。
2. **残留 3 处乱码（有意保留）**：设置画面的字体名 `ＭＳ ゴシック`（config1×2 / config2×1）。
   该串是引擎据以创建字体的**资源名**，改动有失效风险，故不译。
3. **23 处单字符未改动**（`gallery.sob` 11 / `config2.sob` 11 / `title.sob` 1），
   上下文均为递增偏移的数值表，判定为字节码误判（非显示串）。
4. **译文为本次新译**（系统界面文案不在参照汉化覆盖内）；术语按作品术语表与参照汉化
   （`参照\中日对照表.json`）取证，如 `コンドル→空多奴`、`ヨージ→鹰志`、`マルチナス→马汀内斯`、
   `プラチナ→普纳奇纳`。个别新定译标〈待确认〉（如 `吉川 あきら→吉川 明`——あきら 的汉字无据）。
5. **`吉川 あきら` 的给定名无证据**：参照汉化未出现该名的中文写法，暂定「明」，已标〈待确认〉。
6. **voiceinf.dat 的姓氏与作品术语表 §二 不一致**（实测该表为 `羽田 鷹志` / `千歳 鷲介` / `成田 隼人`，
   而 §二 记作 `渡来 鷹志` / `成田 鷲介` / `羽田 隼人` 且本身标〈待确认〉）。
   **本轮一律保留引擎自带的姓氏原字节**（纯汉字，不影响阅读），故未引入冲突；**该姓氏问题另需裁决**。
7. **回滚方式**：`成品\我们没有翅膀R_汉化补丁\` 是新增目录，删除即回滚；原版介质
   `备份\我们没有翅膀R-安装介质\SET_UP\`（16 文件）**未被本轮写入**（仅只读引用）。
8. **未达并行数说明**：翻译拆成 2 个 editor（模块 A＝config 系 153 条；模块 B＝其余 94 条），
   少于 §三.2 建议的 5–10——因为本次是**同一批系统 UI 文案的单一模块**，拆更多份只会
   增加术语漂移风险（术语一致性由主代理口径表统一锁定）。
9. **为修复一审打回项，主代理亲自改写定稿译文**（`fix_sysui_round2.py` 的 `FIX` 表 23 条），
   并把图形类裁决（id32/33/36/37/124）从 `build_sysui.OVERRIDE` 并入该表，**避免两处维护**。
10. **夹心串的中缝全角空格（二审「需知会」项，非打回）**：本作有几处日文被 ASCII 专名
    （`CPU` / `DirectSound` / `Windows` …）**从中间劈开**成一前一后两条池串，中文语序与原文不同，
    于是「译文比原文短」的那部分只能靠**全角空格补齐**，落在句中的逗号后（如 id10 原 8 个、
    id63 原 3 个、id25 10 个、id120 3 个）。
    已把 id10（→「…时，设置是否测量」+`时钟。`）与 id63（→「…时，设置」）压到 0～1 个；
    **剩余中缝无法消除**——整串的渲染长度由「与原文等长」这条硬约束决定，把空格挪到末尾只是换位置。
    **风险等级：外观（观感空白）**，不影响功能；若实测观感不佳，可改为「不译这几条描述」或
    接受加长（须先评估引擎是否裁切）。
